# Tutorial 9: Shader Playground

Write custom GPU shaders and manipulate them in real-time. This is where you stop using graphics APIs and start programming the GPU directly.

## What We're Building

A shader experimentation environment: gallery of visual effects (raymarching, fractals, post-processing), real-time parameter adjustment, custom shader compilation, performance metrics, and multiple render targets.

Think Shadertoy but native, with controls, and you understand exactly how it works.

**Raymarching Shader** (fragment):
```glsl
#version 300 es
precision highp float;

uniform float uTime;
uniform vec2 uResolution;
uniform float uRadius;

out vec4 fragColor;

float sdSphere(vec3 p, float r) {
    return length(p) - r;
}

float sceneSDF(vec3 p) {
    return sdSphere(p, uRadius);
}

float raymarch(vec3 ro, vec3 rd) {
    float t = 0.0;
    for (int i = 0; i < 100; i++) {
        vec3 p = ro + rd * t;
        float d = sceneSDF(p);
        if (d < 0.001) break;
        if (t > 100.0) break;
        t += d;
    }
    return t;
}

vec3 calcNormal(vec3 p) {
    vec2 e = vec2(0.001, 0.0);
    return normalize(vec3(
        sceneSDF(p + e.xyy) - sceneSDF(p - e.xyy),
        sceneSDF(p + e.yxy) - sceneSDF(p - e.yxy),
        sceneSDF(p + e.yyx) - sceneSDF(p - e.yyx)
    ));
}

void main() {
    vec2 uv = (gl_FragCoord.xy / uResolution) * 2.0 - 1.0;
    uv.x *= uResolution.x / uResolution.y;

    vec3 ro = vec3(0.0, 0.0, 3.0);
    vec3 rd = normalize(vec3(uv, -1.0));

    float t = raymarch(ro, rd);

    if (t < 100.0) {
        vec3 p = ro + rd * t;
        vec3 normal = calcNormal(p);
        vec3 lightDir = normalize(vec3(cos(uTime), 1.0, sin(uTime)));
        float diffuse = max(dot(normal, lightDir), 0.0);
        vec3 color = vec3(0.2, 0.5, 0.9) * (0.3 + diffuse * 0.7);
        fragColor = vec4(color, 1.0);
    } else {
        fragColor = vec4(0.1, 0.1, 0.15, 1.0);
    }
}
```

**Mandelbrot Shader**:
```glsl
uniform float uZoom;
uniform vec2 uCenter;
uniform float uIterations;

void main() {
    vec2 uv = (gl_FragCoord.xy / uResolution) * 2.0 - 1.0;
    uv.x *= uResolution.x / uResolution.y;

    vec2 c = uv / uZoom + uCenter;
    vec2 z = vec2(0.0);
    int iterations = 0;

    for (int i = 0; i < int(uIterations); i++) {
        z = vec2(z.x * z.x - z.y * z.y, 2.0 * z.x * z.y) + c;
        if (length(z) > 2.0) {
            iterations = i;
            break;
        }
    }

    float t = float(iterations) / uIterations;
    vec3 color = vec3(t, 1.0 - t, 0.5);
    fragColor = vec4(color, 1.0);
}
```

**Shader Compiler**:
```kotlin
class ShaderCompiler {
    fun compile(effect: ShaderEffect): Int {
        val vertexShader = compileShader(GLES30.GL_VERTEX_SHADER, effect.vertexShader)
        val fragmentShader = compileShader(GLES30.GL_FRAGMENT_SHADER, effect.fragmentShader)

        val program = GLES30.glCreateProgram()
        GLES30.glAttachShader(program, vertexShader)
        GLES30.glAttachShader(program, fragmentShader)
        GLES30.glLinkProgram(program)

        val linked = IntArray(1)
        GLES30.glGetProgramiv(program, GLES30.GL_LINK_STATUS, linked, 0)
        if (linked[0] == 0) {
            throw RuntimeException("Link failed: ${GLES30.glGetProgramInfoLog(program)}")
        }

        return program
    }
}
```

## Common Pitfalls

1. **Shader Compilation Errors**: Only appear at runtime. Check logs.
2. **Infinite Loops**: GPU watchdog kills app after ~5 seconds. Always have loop bounds.
3. **Precision**: Use `highp` for positions, `mediump` for colours.
4. **Uniform Limits**: GLES has max 16 vec4 uniforms in fragment shader.

## Performance Notes

Raymarching 1920×1080 at 60fps on flagship phones: fragment shader ~5ms. Mandelbrot with 100 iterations: ~8ms. GPU is 100× faster than CPU for this workload.
