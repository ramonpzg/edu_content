# Tutorial 5: 3D Scene Explorer

Build a navigable 3D environment with textures, lighting, and gesture-based camera controls.

## What We're Building

A first-person 3D scene viewer: room with textured floor/walls/ceiling, multiple 3D objects with textures, drag to rotate camera, pinch to zoom, and basic directional lighting.

Think architectural walkthrough but less corporate and more "I want to understand how this actually works".

## Key Implementation Points

**Texture Loading**:
```kotlin
fun loadTexture(context: Context, resourceId: Int): Int {
    val textureHandle = IntArray(1)
    GLES30.glGenTextures(1, textureHandle, 0)

    val bitmap = BitmapFactory.decodeResource(context.resources, resourceId)

    GLES30.glBindTexture(GLES30.GL_TEXTURE_2D, textureHandle[0])
    GLES30.glTexParameteri(GLES30.GL_TEXTURE_2D, GLES30.GL_TEXTURE_MIN_FILTER, GLES30.GL_LINEAR)
    GLES30.glTexParameteri(GLES30.GL_TEXTURE_2D, GLES30.GL_TEXTURE_MAG_FILTER, GLES30.GL_LINEAR)

    GLUtils.texImage2D(GLES30.GL_TEXTURE_2D, 0, bitmap, 0)
    bitmap.recycle()

    return textureHandle[0]
}
```

**Camera with Touch Controls** (`Camera.kt`):
```kotlin
class Camera {
    var position = floatArrayOf(0f, 1.6f, 5f)
    var pitch = 0f  // X-axis rotation
    var yaw = 0f    // Y-axis rotation

    fun viewMatrix(): FloatArray {
        val matrix = FloatArray(16)
        Matrix.setIdentityM(matrix, 0)
        Matrix.rotateM(matrix, 0, pitch, 1f, 0f, 0f)
        Matrix.rotateM(matrix, 0, yaw, 0f, 1f, 0f)
        Matrix.translateM(matrix, 0, -position[0], -position[1], -position[2])
        return matrix
    }

    fun rotate(deltaPitch: Float, deltaYaw: Float) {
        pitch += deltaPitch
        yaw += deltaYaw
        pitch = pitch.coerceIn(-89f, 89f)  // Prevent gimbal lock
    }
}
```

**Lighting Shader** (fragment):
```glsl
#version 300 es
precision mediump float;

in vec3 vNormal;
in vec2 vTexCoord;

uniform sampler2D uTexture;
uniform vec3 uLightDir;

out vec4 fragColor;

void main() {
    vec4 texColor = texture(uTexture, vTexCoord);

    float diffuse = max(dot(normalize(vNormal), -uLightDir), 0.0);
    float ambient = 0.3;

    float lighting = ambient + diffuse * 0.7;
    fragColor = vec4(texColor.rgb * lighting, texColor.a);
}
```

**Touch Handling**:
```kotlin
glView.setOnTouchListener { view, event ->
    when (event.actionMasked) {
        MotionEvent.ACTION_MOVE -> {
            if (event.pointerCount == 1) {
                // Rotate camera
                val dx = event.x - lastX
                val dy = event.y - lastY
                camera.rotate(-dy * 0.1f, dx * 0.1f)
            }
        }
    }
    lastX = event.x
    lastY = event.y
    true
}
```

## Performance Notes

Drawing 8 objects (floor + 5 crates + 3 walls) with textures and lighting: ~0.3ms per frame. Bottleneck isn't rendering, it's iteration overhead. For 1000 objects, batch by texture.

## Common Pitfalls

1. **Normal Transformation**: Use normal matrix (inverse-transpose of model matrix) for non-uniform scaling
2. **Texture Coordinates**: Ensure UVs are in [0,1] range
3. **Camera Movement**: Lock to XZ plane for FPS-style movement
