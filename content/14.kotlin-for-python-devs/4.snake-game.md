# Tutorial 4: Snake Game

A classic game to teach you state management, input handling, and game loops in Kotlin. Much less GPU wizardry, much more architecture.

## What We're Building

Snake. You know it: grid-based movement, snake grows when eating food, game over when hitting walls or yourself, touch controls, and score tracking.

We'll use Jetpack Compose for UI and custom Canvas drawing for the grid. Why Canvas instead of OpenGL for simple rectangles? Because drawing 400 coloured rectangles with Compose would be abysmal for performance.

## Python Parallel

```python
import pygame

class Snake:
    def __init__(self):
        self.segments = [(5, 5)]
        self.direction = (1, 0)

    def update(self):
        head = self.segments[0]
        new_head = (head[0] + self.direction[0],
                    head[1] + self.direction[1])
        self.segments.insert(0, new_head)
        self.segments.pop()
```

Kotlin's approach is similar but with stronger typing and value semantics. Instead of tuples, we use data classes.

## Core Implementation

**Game State** (`GameState.kt`):
```kotlin
data class Position(val x: Int, val y: Int)

enum class Direction {
    UP, DOWN, LEFT, RIGHT;

    val delta: Position
        get() = when (this) {
            UP -> Position(0, -1)
            DOWN -> Position(0, 1)
            LEFT -> Position(-1, 0)
            RIGHT -> Position(1, 0)
        }
}

class GameState {
    var snake = mutableListOf(Position(10, 15))
    var food = Position(5, 5)
    var direction = Direction.RIGHT
    var score = 0
    var isGameOver = false

    fun update() {
        if (isGameOver) return

        val head = snake.first()
        val newHead = Position(
            head.x + direction.delta.x,
            head.y + direction.delta.y
        )

        if (isOutOfBounds(newHead) || snake.contains(newHead)) {
            isGameOver = true
            return
        }

        snake.add(0, newHead)

        if (newHead == food) {
            score += 10
            spawnFood()
        } else {
            snake.removeLast()
        }
    }

    private fun isOutOfBounds(pos: Position) =
        pos.x < 0 || pos.x >= GRID_WIDTH ||
        pos.y < 0 || pos.y >= GRID_HEIGHT

    companion object {
        const val GRID_WIDTH = 20
        const val GRID_HEIGHT = 30
    }
}
```

**Compose UI with Canvas Drawing** (`GameScreen.kt`):
```kotlin
@Composable
fun GameScreen() {
    val gameState = remember { GameState() }

    LaunchedEffect(Unit) {
        while (true) {
            delay(150)  // Game tick every 150ms
            gameState.update()
        }
    }

    Column(Modifier.fillMaxSize()) {
        Text("Score: ${gameState.score}")

        Canvas(
            modifier = Modifier
                .weight(1f)
                .fillMaxWidth()
                .pointerInput(Unit) {
                    detectDragGestures { change, dragAmount ->
                        val horizontal = abs(dragAmount.x) > abs(dragAmount.y)
                        gameState.direction = if (horizontal) {
                            if (dragAmount.x > 0) Direction.RIGHT else Direction.LEFT
                        } else {
                            if (dragAmount.y > 0) Direction.DOWN else Direction.UP
                        }
                    }
                }
        ) {
            val cellWidth = size.width / GameState.GRID_WIDTH
            val cellHeight = size.height / GameState.GRID_HEIGHT

            // Draw snake
            gameState.snake.forEach { segment ->
                drawRect(
                    color = Color.Green,
                    topLeft = Offset(
                        segment.x * cellWidth,
                        segment.y * cellHeight
                    ),
                    size = Size(cellWidth * 0.9f, cellHeight * 0.9f)
                )
            }

            // Draw food
            drawRect(
                color = Color.Red,
                topLeft = Offset(
                    gameState.food.x * cellWidth,
                    gameState.food.y * cellHeight
                ),
                size = Size(cellWidth * 0.9f, cellHeight * 0.9f)
            )
        }

        if (gameState.isGameOver) {
            Button(onClick = { /* Restart */ }) {
                Text("Restart")
            }
        }
    }
}
```

**Key Points**:
- `LaunchedEffect`: Coroutine running game loop
- `Canvas`: Custom drawing in Compose
- `pointerInput`: Gesture detection for swipe controls
- Data classes for immutable position

## Common Pitfalls

1. **Direction Buffering**: Allow direction changes mid-update and player can reverse into themselves
2. **Coroutine Lifecycle**: `LaunchedEffect` cancels when composable leaves, preventing leaks
3. **Food Spawning**: Check snake positions to avoid spawning inside snake

## Performance

Drawing 30-100 coloured rectangles with Canvas: ~0.5ms per frame. Same with Compose `Box()` views: ~5ms (10× slower). For static UI, Compose is fine. For dynamic game rendering, Canvas wins.
