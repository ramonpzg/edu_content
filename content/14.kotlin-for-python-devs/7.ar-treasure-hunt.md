# Tutorial 7: AR Treasure Hunt

Build an augmented reality game where virtual objects exist in physical space. This is where Android leaves Python in the dust.

## What We're Building

An AR scavenger hunt: camera feed shows real world, virtual treasures spawn at random locations, plane detection finds floors/tables, tap treasures to collect them, score tracking, distance indicators, and works indoors/outdoors.

## Python Parallel

Python has AR frameworks (OpenCV + ArUco markers), but nothing like ARCore's integration. ARCore does markerless AR: visual-inertial odometry, SLAM, plane detection, light estimation, and hardware-accelerated ML.

## Implementation Highlights

**ARCore Setup** (`build.gradle`):
```gradle
dependencies {
    implementation 'com.google.ar:core:1.39.0'
    implementation 'com.google.ar.sceneform:core:1.17.1'
}
```

**AR Activity**:
```kotlin
class ARActivity : AppCompatActivity() {
    private lateinit var arFragment: ArFragment
    private val treasures = mutableListOf<AnchorNode>()
    private var score = 0

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_ar)

        arFragment = supportFragmentManager.findFragmentById(R.id.ar_fragment) as ArFragment

        arFragment.setOnTapArPlaneListener { hitResult, plane, motionEvent ->
            if (treasures.size < 5) {
                spawnTreasure(hitResult.createAnchor())
            }
        }

        checkARAvailability()
    }

    private fun spawnTreasure(anchor: Anchor) {
        val anchorNode = AnchorNode(anchor).apply {
            setParent(arFragment.arSceneView.scene)
        }

        MaterialFactory.makeOpaqueWithColor(this, Color(android.graphics.Color.YELLOW))
            .thenAccept { material ->
                val model = ShapeFactory.makeCube(Vector3(0.1f, 0.1f, 0.1f), Vector3.zero(), material)
                val modelNode = Node().apply {
                    setParent(anchorNode)
                    renderable = model
                    setOnTapListener { _, _ ->
                        collectTreasure(anchorNode)
                    }
                }
                treasures.add(anchorNode)
            }
    }

    private fun collectTreasure(node: AnchorNode) {
        node.anchor?.detach()
        node.setParent(null)
        treasures.remove(node)
        score += 100
        updateScore()
    }

    private fun checkARAvailability() {
        ArCoreApk.getInstance().requestInstall(this, true)
    }
}
```

**Plane Detection**:

```kotlin
arFragment.arSceneView.scene.addOnUpdateListener { frameTime ->
    val frame = arFragment.arSceneView.arFrame ?: return@addOnUpdateListener

    // Get detected planes
    frame.getUpdatedTrackables(Plane::class.java).forEach { plane ->
        if (plane.trackingState == TrackingState.TRACKING) {
            // Plane detected and being tracked
            visualizePlane(plane)
        }
    }
}
```

**Distance Calculation**:
```kotlin
fun distanceToCamera(node: Node, camera: Camera): Float {
    val nodePos = node.worldPosition
    val cameraPos = camera.worldPosition
    return Vector3.subtract(nodePos, cameraPos).length()
}
```

## Common Pitfalls

1. **Tracking Failure**: ARCore needs textured surfaces. Blank walls fail.
2. **Permissions**: Need camera permission in manifest.
3. **ARCore Installation**: Not all devices support ARCore. Check availability.
4. **Scale Confusion**: ARCore uses meters. 1.0 = 1 meter, not 1 pixel.

## Performance Notes

ARCore runs at 30-60fps depending on device. CPU overhead: ~10ms (tracking), GPU: ~5ms (rendering). Total: ~15ms, well under budget.
