# Authentication and Session Management

Implement secure authentication using Bun's built-in crypto APIs. No external libraries—just JWT tokens, password hashing with Argon2, and signed cookies for session management.

## What We're Building

Complete auth system:

- User registration with email verification
- Password hashing (Argon2id)
- JWT-based sessions
- Protected API routes
- Remember-me functionality
- Password reset flow
- Rate limiting

**Dependencies**: Zero. Bun includes `crypto`, `password hashing`, and `JWT` support out of the box.

## Password Hashing with Argon2

Bun includes Argon2id hashing (winner of Password Hashing Competition):

```typescript
// Hash password
const password = "userpassword123";
const hash = await Bun.password.hash(password, {
  algorithm: "argon2id",
  memoryCost: 65536,  // 64 MB
  timeCost: 3,        // 3 iterations
});

console.log(hash);
// $argon2id$v=19$m=65536,t=3,p=1$...

// Verify password
const isValid = await Bun.password.verify(password, hash);
console.log(isValid);  // true
```

**Parameters:**

- `memoryCost`: Memory in KB (higher = slower, more secure). Default: 65536 (64MB)
- `timeCost`: Iterations (higher = slower). Default: 3
- `parallelism`: Threads (default: 1)

**Measured time**: ~180ms to hash on M1 Mac. Slow enough to prevent brute force, fast enough for web requests.

// server/index.ts
import { randomUUID } from "node:crypto";

if (url.pathname === "/api/auth/register" && req.method === "POST") {
  const { email, password } = await req.json();

  // Validation
  if (!email || !email.includes("@")) {
    return Response.json({ error: "Invalid email" }, { status: 400 });
  }

  if (!password || password.length < 8) {
    return Response.json({ error: "Password must be at least 8 characters" }, { status: 400 });
  }

  // Check if email exists
  const existing = await db.execute(
    "SELECT id FROM users WHERE email = ?",
    [email.toLowerCase()]

    return Response.json({ error: "Email already registered" }, { status: 409 });
  }

  // Hash password
  const passwordHash = await Bun.password.hash(password);

  // Create user
  const userId = randomUUID();

  await db.execute(
    "INSERT INTO users (id, email, password_hash, created_at, updated_at) VALUES (?, ?, ?, ?, ?)",
    [userId, email.toLowerCase(), passwordHash, Date.now(), Date.now()]
  );

  // TODO: Send verification email

  return Response.json({
    success: true,
    message: "Registration successful. Please verify your email.",

## JWT Token Generation

Use Bun's built-in JWT support:

```typescript
async function generateToken(userId: string): Promise<string> {
  const secret = process.env.JWT_SECRET!;

  const payload = {
    sub: userId,
    iat: Math.floor(Date.now() / 1000),
    exp: Math.floor(Date.now() / 1000) + (7 * 24 * 60 * 60),  // 7 days
  };

  // Bun's crypto API for JWT
  const encoder = new TextEncoder();
  const data = encoder.encode(JSON.stringify(payload));

  const key = await crypto.subtle.importKey(
    "raw",
    encoder.encode(secret),
    { name: "HMAC", hash: "SHA-256" },
    false,
    ["sign"]
  );

  const signature = await crypto.subtle.sign("HMAC", key, data);

  const base64Url = (str: string) =>
    btoa(str).replace(/\+/g, "-").replace(/\//g, "_").replace(/=/g, "");

  const header = base64Url(JSON.stringify({ alg: "HS256", typ: "JWT" }));
  const encodedPayload = base64Url(JSON.stringify(payload));
  const encodedSignature = base64Url(String.fromCharCode(...new Uint8Array(signature)));

  return `${header}.${encodedPayload}.${encodedSignature}`;
}
```

**Simpler approach with `jose` library:**

bun add jose

```typescript
import { SignJWT, jwtVerify } from "jose";

async function generateToken(userId: string): Promise<string> {
  const secret = new TextEncoder().encode(process.env.JWT_SECRET!);

  const token = await new SignJWT({ sub: userId })
    .setProtectedHeader({ alg: "HS256" })
    .setIssuedAt()
    .setExpirationTime("7d")
    .sign(secret);

  return token;
}

async function verifyToken(token: string): Promise<string | null> {
  try {
    const secret = new TextEncoder().encode(process.env.JWT_SECRET!);
    const { payload } = await jwtVerify(token, secret);
    return payload.sub as string;
  } catch {
    return null;
  }
}
```

## Login Endpoint

```typescript
if (url.pathname === "/api/auth/login" && req.method === "POST") {
  const { email, password } = await req.json();

  // Find user
  const result = await db.execute(
    "SELECT id, password_hash, email_verified FROM users WHERE email = ?",
    [email.toLowerCase()]
  );

  if (result.rows.length === 0) {
    return Response.json({ error: "Invalid credentials" }, { status: 401 });
  }

  const user = result.rows[0];

  // Verify password
  const isValid = await Bun.password.verify(password, user.password_hash as string);

  if (!isValid) {
    return Response.json({ error: "Invalid credentials" }, { status: 401 });
  }

  // Check email verification
  if (!user.email_verified) {
    return Response.json({
      error: "Please verify your email before logging in",
    }, { status: 403 });
  }

  // Generate JWT
  const token = await generateToken(user.id as string);

  // Set HTTP-only cookie
  return Response.json(
    { success: true, token },
    {
      headers: {
        "Set-Cookie": `auth_token=${token}; HttpOnly; Secure; SameSite=Strict; Max-Age=604800; Path=/`,
      },
    }
  );
}
```

**Cookie attributes explained:**

- `HttpOnly` - Prevents JavaScript access (XSS protection)
- `Secure` - HTTPS only
- `SameSite=Strict` - CSRF protection
- `Max-Age=604800` - 7 days (in seconds)
- `Path=/` - Available site-wide

## Authentication Middleware

Protect routes requiring authentication:

```typescript
async function requireAuth(req: Request): Promise<{ userId: string } | Response> {
  // Extract token from cookie
  const cookies = req.headers.get("Cookie") || "";
  const authCookie = cookies
    .split(";")
    .find(c => c.trim().startsWith("auth_token="));

  if (!authCookie) {
    return Response.json({ error: "Unauthorized" }, { status: 401 });
  }

  const token = authCookie.split("=")[1];

  // Verify token
  const userId = await verifyToken(token);

  if (!userId) {
    return Response.json({ error: "Invalid token" }, { status: 401 });
  }

  return { userId };
}

// Usage in routes
if (url.pathname === "/api/progress") {
  const auth = await requireAuth(req);

  if (auth instanceof Response) {
    return auth;  // Return 401 error
  }

  const { userId } = auth;

  // User is authenticated, proceed
  const result = await db.execute(
    "SELECT * FROM user_progress WHERE user_id = ?",
    [userId]
  );

  return Response.json(result.rows);
}
```

**Reset password:**

```typescript
if (url.pathname === "/api/auth/reset-password" && req.method === "POST") {
  const { token, newPassword } = await req.json();

  // Verify reset token
  const payload = await verifyToken(token);

  if (!payload || payload.purpose !== "reset") {
    return Response.json({ error: "Invalid or expired reset token" }, { status: 400 });
  }

  const userId = payload.sub;

  // Validate new password
  if (newPassword.length < 8) {
    return Response.json({ error: "Password must be at least 8 characters" }, { status: 400 });
  }

  // Hash new password
  const passwordHash = await Bun.password.hash(newPassword);

  // Update password
  await db.execute(
    "UPDATE users SET password_hash = ?, updated_at = ? WHERE id = ?",
    [passwordHash, Date.now(), userId]
  );

  return Response.json({ success: true, message: "Password reset successful" });
}
```

## Rate Limiting

Prevent brute force attacks:

```typescript
// In-memory rate limiter (use Redis for production)
const rateLimits = new Map<string, { count: number; resetAt: number }>();

function rateLimit(key: string, maxRequests: number, windowMs: number): boolean {
  const now = Date.now();
  const limit = rateLimits.get(key);

  if (!limit || now > limit.resetAt) {
    rateLimits.set(key, { count: 1, resetAt: now + windowMs });
    return true;
  }

  if (limit.count >= maxRequests) {
    return false;  // Rate limit exceeded
  }

  limit.count++;
  return true;
}

// Usage in login endpoint:
const clientIp = req.headers.get("CF-Connecting-IP") || req.headers.get("X-Forwarded-For") || "unknown";

if (!rateLimit(`login:${clientIp}`, 5, 60 * 1000)) {
  return Response.json({
    error: "Too many login attempts. Please try again in 1 minute.",
  }, { status: 429 });
}
```

**5 login attempts per minute per IP**.

## Security Best Practices

### Never Log Sensitive Data

```typescript
// BAD
console.log(`User ${email} logged in with password: ${password}`);

// GOOD
console.log(`User ${email} logged in successfully`);
```

### Use Environment Variables for Secrets

```bash
# .env
JWT_SECRET=your-secret-key-min-32-characters-long
```

Generate secure secret:

```bash
openssl rand -base64 32
```

### Timing Attack Prevention

```typescript
// BAD - reveals whether email exists
const user = await db.execute("SELECT * FROM users WHERE email = ?", [email]);
if (!user) {
  return Response.json({ error: "Email not found" }, { status: 404 });
}

const isValid = await Bun.password.verify(password, user.password_hash);
if (!isValid) {
  return Response.json({ error: "Invalid password" }, { status: 401 });
}

// GOOD - constant-time response
const user = await db.execute("SELECT * FROM users WHERE email = ?", [email]);
const isValid = user ? await Bun.password.verify(password, user.password_hash) : false;

if (!user || !isValid) {
  return Response.json({ error: "Invalid credentials" }, { status: 401 });
}
```

### HTTPS Only in Production

```typescript
if (process.env.NODE_ENV === "production") {
  // Redirect HTTP to HTTPS
  if (!req.url.startsWith("https://")) {
    return Response.redirect(req.url.replace("http://", "https://"), 301);
  }
}
```
