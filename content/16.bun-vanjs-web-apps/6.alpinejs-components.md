# Interactive Components with AlpineJS

Build rich client-side widgets with AlpineJS's reactive directives. Add code playgrounds, tabbed interfaces, accordions, and tooltips—all without writing JavaScript files.

## What We're Building

Interactive components:

- Live code editor with syntax highlighting
- Tabbed lesson navigation
- Accordion FAQ section
- Copy-to-clipboard buttons
- Keyboard shortcuts
- Dark mode toggle

**Bundle size**: 15KB AlpineJS + 0KB application code. Everything declared in HTML attributes.

## Installation

```html
<!-- client/index.html -->
<script defer src="https://cdn.jsdelivr.net/npm/alpinejs@3.14.4/dist/cdn.min.js"></script>
```

Or install locally:

```bash
bun add alpinejs
```

## Basic Patterns

### Counter (State Management)

```html
<div x-data="{ count: 0 }">
  <button @click="count++">Increment</button>
  <span x-text="count"></span>
</div>
```

**Breakdown:**

- `x-data="{ count: 0 }"` - Initialize component state
- `@click="count++"` - Event listener (shorthand for `x-on:click`)
- `x-text="count"` - Bind text content to state

### Toggle Visibility

```html
<div x-data="{ open: false }">
  <button @click="open = !open">Toggle Details</button>

  <div x-show="open"
       x-transition>
    <p>Hidden content revealed!</p>
  </div>
</div>
```

`x-show` toggles `display: none`. `x-transition` adds CSS transitions automatically.

### Form Input Binding

```html
<div x-data="{ search: '' }">
  <input type="text" x-model="search" placeholder="Search...">
  <p x-show="search.length > 0">
    Searching for: <strong x-text="search"></strong>
  </p>
</div>
```

`x-model="search"` creates two-way binding (like `v-model` in Vue).

## Code Playground Component

Live editor with execution:

```html
<div x-data="codePlayground()">
  <!-- Editor -->
  <div>
    <label>JavaScript Code:</label>
    <textarea
      x-model="code"
      @input.debounce.500ms="execute()"
      rows="10"
      cols="80"
      class="code-editor"
    ></textarea>
  </div>

  <!-- Output -->
  <div>
    <strong>Output:</strong>
    <pre x-text="output" class="output"></pre>
  </div>

  <!-- Error -->
  <div x-show="error" class="error">
    <strong>Error:</strong>
    <pre x-text="error"></pre>
  </div>

  <!-- Controls -->
  <button @click="execute()">Run Code</button>
  <button @click="reset()">Reset</button>
</div>

<script>
function codePlayground() {
  return {
    code: '// Try: console.log("Hello")\nfunction add(a, b) {\n  return a + b;\n}\n\nadd(2, 3);',
    output: '',
    error: null,

    execute() {
      this.output = '';
      this.error = null;

      try {
        // Capture console.log
        const logs = [];
        const originalLog = console.log;
        console.log = (...args) => {
          logs.push(args.map(a => JSON.stringify(a)).join(' '));
        };

        // Execute code
        const result = eval(this.code);

        // Restore console.log
        console.log = originalLog;

        // Display output
        this.output = [...logs, result !== undefined ? `→ ${result}` : ''].join('\n');

      } catch (e) {
        console.log = originalLog;
        this.error = e.message;
      }
    },

    reset() {
      this.code = '// Write your code here';
      this.output = '';
      this.error = null;
    }
  };
}
</script>
```

**Features:**

- `@input.debounce.500ms` - Auto-run code 500ms after typing stops
- `eval()` - Execute user code (safe in educational context, **never** in production with untrusted input)
- Console capturing - Shows `console.log()` output

**Enhanced version with syntax highlighting:**

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/prismjs@1.29.0/themes/prism-tomorrow.min.css">
<script src="https://cdn.jsdelivr.net/npm/prismjs@1.29.0/components/prism-core.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/prismjs@1.29.0/components/prism-javascript.min.js"></script>

  <!-- Syntax-highlighted display -->

  <script>
  function codePlayground() {
    return {
      code: '...',

      highlighted() {
        return Prism.highlight(this.code, Prism.languages.javascript, 'javascript');
      },

      // ... rest of methods
    };
  }
  </script>
</div>
```

## Tabbed Interface

Switch between lesson sections:

```html
<div x-data="{ tab: 'overview' }">
  <!-- Tab headers -->
  <nav class="tabs">
    <button @click="tab = 'overview'" :class="{ active: tab === 'overview' }">
      Overview
    </button>
    <button @click="tab = 'code'" :class="{ active: tab === 'code' }">
      Code
    </button>
    <button @click="tab = 'exercises'" :class="{ active: tab === 'exercises' }">
      Exercises
    </button>
  </nav>

  <!-- Tab content -->
  <div x-show="tab === 'overview'" x-transition>
    <h2>Lesson Overview</h2>
    <p>Introduction to the topic...</p>
  </div>

  <div x-show="tab === 'code'" x-transition>
    <h2>Code Examples</h2>
    <pre><code>const example = "code";</code></pre>
  </div>

  <div x-show="tab === 'exercises'" x-transition>
    <h2>Practice Exercises</h2>
    <ol>
      <li>Exercise 1...</li>
      <li>Exercise 2...</li>
    </ol>
  </div>
</div>
```

**Keyboard shortcuts:**

```html
<div x-data="{ tab: 'overview' }"
     @keydown.window.1="tab = 'overview'"
     @keydown.window.2="tab = 'code'"
     @keydown.window.3="tab = 'exercises'">
  <!-- Press 1, 2, 3 to switch tabs -->
</div>
```

## Copy-to-Clipboard

```html
<div x-data="{ copied: false }">
  <pre><code id="code-snippet">const server = Bun.serve({ port: 3000 });</code></pre>

  <button @click="
    navigator.clipboard.writeText(document.getElementById('code-snippet').textContent);
    copied = true;
    setTimeout(() => copied = false, 2000);
  ">
    <span x-show="!copied">Copy Code</span>
    <span x-show="copied">Copied!</span>
  </button>
</div>
```

**Reusable component:**

```html
<template x-component="copyButton">
  <div x-data="{ copied: false }">
    <button @click="
      navigator.clipboard.writeText($el.closest('pre').textContent);
      copied = true;
      setTimeout(() => copied = false, 2000);
    ">
      <span x-show="!copied">📋</span>
      <span x-show="copied">✓</span>
    </button>
  </div>
</template>

<!-- Usage: -->
<pre><code>...</code></pre>
<div x-component="copyButton"></div>
```

## Dark Mode Toggle

```html
<div x-data="darkMode()"
     :class="{ 'dark': dark }">

  <button @click="toggle()">
    <span x-show="!dark">🌙 Dark Mode</span>
    <span x-show="dark">☀️ Light Mode</span>
  </button>

  <main>
    <!-- App content -->
  </main>
</div>

<script>
function darkMode() {
  return {
    dark: localStorage.getItem('darkMode') === 'true',

    init() {
      // Apply on mount
      document.documentElement.classList.toggle('dark', this.dark);
    },

    toggle() {
      this.dark = !this.dark;
      localStorage.setItem('darkMode', this.dark);
      document.documentElement.classList.toggle('dark', this.dark);
    }
  };
}
</script>

<style>
:root {
  --bg: #ffffff;
  --text: #000000;
}

:root.dark {
  --bg: #0d0d0d;
  --text: #e0e0e0;
}

body {
  background: var(--bg);
  color: var(--text);
}
</style>
```

**Respects system preference:**

```javascript
function darkMode() {
  return {
    dark: localStorage.getItem('darkMode')
      ? localStorage.getItem('darkMode') === 'true'
      : window.matchMedia('(prefers-color-scheme: dark)').matches,

    init() {
      document.documentElement.classList.toggle('dark', this.dark);
    },

    toggle() {
      this.dark = !this.dark;
      localStorage.setItem('darkMode', this.dark);
      document.documentElement.classList.toggle('dark', this.dark);
    }
  };
}
```

## Keyboard Shortcuts Panel

```html
<div x-data="shortcuts()"
     @keydown.window="handleKey($event)">

  <!-- Show shortcuts panel with ? key -->
  <div x-show="showPanel"
       @click.away="showPanel = false"
       class="shortcuts-panel">
    <h3>Keyboard Shortcuts</h3>
    <dl>
      <dt>?</dt><dd>Show this panel</dd>
      <dt>Esc</dt><dd>Close panels</dd>
      <dt>1-9</dt><dd>Navigate tabs</dd>
      <dt>Ctrl+Enter</dt><dd>Run code</dd>
      <dt>n</dt><dd>Next lesson</dd>
      <dt>p</dt><dd>Previous lesson</dt>
    </dl>
  </div>
</div>

<script>
function shortcuts() {
  return {
    showPanel: false,

    handleKey(event) {
      // ? key - show shortcuts
      if (event.key === '?' && !event.ctrlKey && !event.metaKey) {
        event.preventDefault();
        this.showPanel = !this.showPanel;
      }

      // Escape - close panel
      if (event.key === 'Escape') {
        this.showPanel = false;
      }

      // Ctrl+Enter - run code (dispatch custom event)
      if (event.key === 'Enter' && (event.ctrlKey || event.metaKey)) {
        event.preventDefault();
        this.$dispatch('run-code');
      }

      // n/p - navigation
      if (event.key === 'n' && !this.showPanel) {
        this.$dispatch('next-lesson');
      }

      if (event.key === 'p' && !this.showPanel) {
        this.$dispatch('prev-lesson');
      }
    }
  };
}
</script>
```

**Listen to custom events:**

```html
<div @run-code.window="executeCode()">
  <!-- Code playground -->
</div>

<div @next-lesson.window="goToNext()">
  <!-- Lesson navigation -->
</div>
```

## AlpineJS + HTMX Integration

Combine Alpine's client-side reactivity with HTMX's server updates:

```html
<div x-data="{ filter: 'all' }">
  <!-- Client-side filter (Alpine) -->
  <select x-model="filter">
    <option value="all">All Categories</option>
    <option value="fundamentals">Fundamentals</option>
    <option value="advanced">Advanced</option>
  </select>

  <!-- Server-side load (HTMX) -->
  <div hx-get="/api/lessons"
       hx-trigger="load"
       :hx-vals='{ category: filter }'
       @change.window="htmx.trigger(this, 'load')">
    Loading lessons...
  </div>
</div>
```

When `filter` changes, triggers HTMX reload with new category parameter.

## Shared State Between Components

Use Alpine store:

```html
<script>
document.addEventListener('alpine:init', () => {
  Alpine.store('progress', {
    completed: [],

    markComplete(slug) {
      if (!this.completed.includes(slug)) {
        this.completed.push(slug);
        localStorage.setItem('progress', JSON.stringify(this.completed));
      }
    },

    isComplete(slug) {
      return this.completed.includes(slug);
    },

    init() {
      const saved = localStorage.getItem('progress');
      if (saved) {
        this.completed = JSON.parse(saved);
      }
    }
  });
});
</script>

<!-- Component 1: Mark complete button -->
<button @click="$store.progress.markComplete('bun-fundamentals')">
  Mark Complete
</button>

<!-- Component 2: Progress indicator -->
<span x-text="$store.progress.completed.length"></span> lessons completed

<!-- Component 3: Lesson status -->
<div x-show="$store.progress.isComplete('bun-fundamentals')">
  ✓ You've completed this lesson
</div>
```

`Alpine.store` creates global reactive state accessible via `$store`.

## Performance Comparison

| Metric | AlpineJS | VanJS | React |
|--------|----------|-------|-------|
| **Bundle size** | 15KB | 1KB | 45KB (preact) |
| **Initial render** | Instant (no compilation) | 3ms | 12ms |
| **Re-render** | 1-2ms | 1-2ms | 3-5ms |
| **Learning curve** | Minimal (HTML-first) | Low (JS-first) | Moderate |
| **Best for** | Sprinkles of interactivity | SPA core | Complex apps |

**AlpineJS shines** for progressive enhancement. Add interactivity to server-rendered HTML without rewriting everything in JavaScript.

## Common Pitfalls

### Forgetting x-data

```html
<!-- WRONG - Alpine directives ignored -->
<button @click="count++">Click</button>

<!-- RIGHT - needs x-data scope -->
<div x-data="{ count: 0 }">
  <button @click="count++">Click</button>
  <span x-text="count"></span>
</div>
```

### Using eval() with User Input

**Never** execute untrusted code:

```html
<!-- DANGEROUS if code comes from users -->
<button @click="eval(userCode)">Run</button>
```

Code playground example is safe only for **educational** purposes where users execute code in their own browser. For production, use sandboxed iframes or WebAssembly.

### Memory Leaks with Intervals

```html
<div x-data="{ count: 0 }"
     x-init="setInterval(() => count++, 1000)">
  <!-- Memory leak: interval never cleared -->
</div>
```

**Fix:**

```html
<div x-data="{ count: 0, interval: null }"
     x-init="interval = setInterval(() => count++, 1000)"
     x-destroy="clearInterval(interval)">
  <!-- Properly cleaned up -->
</div>
```
