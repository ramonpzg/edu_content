# Tutorial 10: Multiplayer Sketchpad

Build a collaborative drawing app with CRDTs (Conflict-free Replicated Data Types). Multiple users draw simultaneously without conflicts. This is where distributed systems meet graphics programming.

## What We're Building

A real-time multiplayer sketchpad featuring:
- Draw with touch (pressure-sensitive strokes)
- Multiple concurrent users (10+)
- Conflict-free merging of concurrent edits
- Network synchronisation via WebSocket
- Offline mode with automatic sync when reconnected
- Undo/redo with CRDT semantics
- Stroke smoothing and rendering optimisation
- Cursors showing other users' positions
- Color and brush size selection

Think Google Docs but for drawing, and you understand the underlying CRDT mathematics.

## Python Parallel: Operational Transformation vs CRDTs

Python collaborative editing typically uses Operational Transformation (OT):
```python
class Operation:
    def transform(self, other):
        # Complex transformation logic
        # Depends on operation order
        pass

# OT requires central server to sequence operations
```

CRDTs are different:
- **No central authority** needed (peer-to-peer works)
- **Commutative**: Operations can be applied in any order
- **Convergent**: All replicas eventually reach same state

Python has CRDT libraries (automerge-py), but Swift lets us implement from scratch to understand the mechanics.

## Core Concepts

### CRDTs Fundamentals

**Conflict-free Replicated Data Type**: Data structure where:
1. Concurrent updates can be merged deterministically
2. Merge operation is commutative and associative
3. All replicas converge to same state

Example - LWW (Last-Write-Wins) Register:
```swift
struct LWWRegister<T> {
    var value: T
    var timestamp: UInt64
    var replicaID: UUID

    mutating func merge(_ other: LWWRegister<T>) {
        // Later timestamp wins
        if other.timestamp > timestamp {
            self = other
        } else if other.timestamp == timestamp {
            // Tie-break by replica ID (deterministic)
            if other.replicaID.uuidString > replicaID.uuidString {
                self = other
            }
        }
    }
}
```

Both replicas apply same merge logic → same result regardless of operation order.

### Stroke Representation

Drawing stroke = ordered sequence of points with timestamps:
```swift
struct Stroke {
    var id: UUID
    var points: [StrokePoint]
    var color: SIMD4<Float>
    var width: Float
    var timestamp: UInt64
}

struct StrokePoint {
    var position: SIMD2<Float>
    var pressure: Float
    var timestamp: UInt64
}
```

CRDT property: Strokes are append-only (points only added, never modified). Deletion uses tombstones.

### Vector Clocks for Causality

Track causality between events:
```swift
struct VectorClock {
    private var clocks: [UUID: UInt64] = [:]

    mutating func increment(for replica: UUID) {
        clocks[replica, default: 0] += 1
    }

    func happenedBefore(_ other: VectorClock) -> Bool {
        // All our timestamps ≤ other's, and at least one is strictly less
        var foundLess = false
        for (replica, time) in clocks {
            if time > (other.clocks[replica] ?? 0) {
                return false
            }
            if time < (other.clocks[replica] ?? 0) {
                foundLess = true
            }
        }
        return foundLess
    }
}
```

Detects causally related events vs concurrent events.

## Implementation

### Step 1: CRDT Building Blocks

`CRDT/LWWRegister.swift`:
```swift
import Foundation

struct LWWRegister<T: Codable>: Codable {
    var value: T
    var timestamp: UInt64
    var replicaID: UUID

    init(value: T, timestamp: UInt64 = Clock.now(), replicaID: UUID = Device.id) {
        self.value = value
        self.timestamp = timestamp
        self.replicaID = replicaID
    }

    mutating func set(_ newValue: T) {
        self.value = newValue
        self.timestamp = Clock.now()
        self.replicaID = Device.id
    }

    mutating func merge(_ other: LWWRegister<T>) {
        if other.timestamp > timestamp {
            self = other
        } else if other.timestamp == timestamp {
            if other.replicaID.uuidString > replicaID.uuidString {
                self = other
            }
        }
    }
}

enum Clock {
    private static var logicalTime: UInt64 = 0

    static func now() -> UInt64 {
        logicalTime += 1
        return logicalTime
    }
}

enum Device {
    static let id = UUID()
}
```

Logical clock increments monotonically. Hybrid logical clock (HLC) would use wall-clock time for better ordering.

`CRDT/ORSet.swift` (Observed-Remove Set):
```swift
import Foundation

struct ORSet<T: Hashable & Codable>: Codable {
    private var elements: [T: Set<UUID>] = [:]  // Element -> Set of unique tags

    mutating func insert(_ element: T) {
        let tag = UUID()
        elements[element, default: []].insert(tag)
    }

    mutating func remove(_ element: T) {
        elements[element] = []
    }

    func contains(_ element: T) -> Bool {
        guard let tags = elements[element] else { return false }
        return !tags.isEmpty
    }

    var allElements: Set<T> {
        Set(elements.filter { !$0.value.isEmpty }.keys)
    }

    mutating func merge(_ other: ORSet<T>) {
        for (element, tags) in other.elements {
            elements[element, default: []].formUnion(tags)
        }
    }
}
```

**ORSet**: Add-wins semantics. Element exists if it has any unique tags. Removes observed tags only.

### Step 2: Stroke CRDT

`CRDT/StrokeCRDT.swift`:
```swift
import Foundation
import simd

struct StrokeCRDT: Codable {
    var strokes: ORSet<Stroke> = ORSet()
    var deletedStrokes: Set<UUID> = []

    mutating func addStroke(_ stroke: Stroke) {
        strokes.insert(stroke)
    }

    mutating func deleteStroke(id: UUID) {
        deletedStrokes.insert(id)
    }

    func visibleStrokes() -> [Stroke] {
        strokes.allElements.filter { !deletedStrokes.contains($0.id) }
    }

    mutating func merge(_ other: StrokeCRDT) {
        strokes.merge(other.strokes)
        deletedStrokes.formUnion(other.deletedStrokes)
    }
}

struct Stroke: Hashable, Codable, Identifiable {
    var id: UUID
    var points: [StrokePoint]
    var color: CodableColor
    var width: Float
    var ownerID: UUID
    var createdAt: UInt64

    func hash(into hasher: inout Hasher) {
        hasher.combine(id)
    }

    static func ==(lhs: Stroke, rhs: Stroke) -> Bool {
        lhs.id == rhs.id
    }
}

struct StrokePoint: Hashable, Codable {
    var position: CodableVector2
    var pressure: Float
    var timestamp: UInt64
}

// Wrappers for SIMD types (not Codable by default)
struct CodableVector2: Hashable, Codable {
    var x: Float
    var y: Float

    var simd: SIMD2<Float> {
        SIMD2(x, y)
    }

    init(_ v: SIMD2<Float>) {
        x = v.x
        y = v.y
    }
}

struct CodableColor: Hashable, Codable {
    var r: Float
    var g: Float
    var b: Float
    var a: Float

    var simd: SIMD4<Float> {
        SIMD4(r, g, b, a)
    }

    init(_ v: SIMD4<Float>) {
        r = v.x
        g = v.y
        b = v.z
        a = v.w
    }
}
```

**Design Decisions**:
- Strokes immutable after creation (append-only)
- Deletion uses tombstones (deletedStrokes set)
- ORSet ensures concurrent strokes both appear
- Stroke equality based on UUID only

### Step 3: WebSocket Client

`Networking/WebSocketClient.swift`:
```swift
import Foundation
import Combine

class WebSocketClient: NSObject, ObservableObject, URLSessionWebSocketDelegate {
    @Published var isConnected = false

    private var webSocketTask: URLSessionWebSocketTask?
    private var pingTimer: Timer?

    let messageSubject = PassthroughSubject<Data, Never>()

    func connect(to url: URL) {
        let session = URLSession(configuration: .default, delegate: self, delegateQueue: nil)
        webSocketTask = session.webSocketTask(with: url)
        webSocketTask?.resume()

        receiveMessage()
        startPing()
    }

    func disconnect() {
        webSocketTask?.cancel(with: .goingAway, reason: nil)
        pingTimer?.invalidate()
    }

    func send(data: Data) {
        let message = URLSessionWebSocketTask.Message.data(data)
        webSocketTask?.send(message) { error in
            if let error = error {
                print("WebSocket send error: \(error)")
            }
        }
    }

    private func receiveMessage() {
        webSocketTask?.receive { [weak self] result in
            switch result {
            case .success(let message):
                switch message {
                case .data(let data):
                    self?.messageSubject.send(data)
                case .string(let text):
                    if let data = text.data(using: .utf8) {
                        self?.messageSubject.send(data)
                    }
                @unknown default:
                    break
                }

                // Continue receiving
                self?.receiveMessage()

            case .failure(let error):
                print("WebSocket receive error: \(error)")
            }
        }
    }

    private func startPing() {
        pingTimer = Timer.scheduledTimer(withTimeInterval: 30, repeats: true) { [weak self] _ in
            self?.webSocketTask?.sendPing { error in
                if let error = error {
                    print("Ping failed: \(error)")
                }
            }
        }
    }

    // MARK: - URLSessionWebSocketDelegate

    func urlSession(_ session: URLSession, webSocketTask: URLSessionWebSocketTask,
                   didOpenWithProtocol protocol: String?) {
        DispatchQueue.main.async {
            self.isConnected = true
        }
    }

    func urlSession(_ session: URLSession, webSocketTask: URLSessionWebSocketTask,
                   didCloseWith closeCode: URLSessionWebSocketTask.CloseCode, reason: Data?) {
        DispatchQueue.main.async {
            self.isConnected = false
        }
    }
}
```

**WebSocket Notes**:
- **Combine Integration**: `PassthroughSubject` for incoming messages
- **Automatic Reconnection**: Not implemented here, but would use exponential backoff
- **Ping/Pong**: Keep connection alive (some proxies close idle connections)

### Step 4: Sync Engine

`Networking/SyncEngine.swift`:
```swift
import Foundation
import Combine

class SyncEngine: ObservableObject {
    @Published var localState: StrokeCRDT = StrokeCRDT()
    @Published var users: [UUID: RemoteUser] = [:]

    private let webSocket: WebSocketClient
    private var cancellables = Set<AnyCancellable>()

    let localUserID = Device.id

    init(webSocket: WebSocketClient) {
        self.webSocket = webSocket

        // Subscribe to incoming messages
        webSocket.messageSubject
            .sink { [weak self] data in
                self?.handleMessage(data)
            }
            .store(in: &cancellables)
    }

    func connect(to url: URL) {
        webSocket.connect(to: url)
    }

    func addStroke(_ stroke: Stroke) {
        localState.addStroke(stroke)
        broadcastState()
    }

    func deleteStroke(id: UUID) {
        localState.deleteStroke(id: id)
        broadcastState()
    }

    private func broadcastState() {
        let message = SyncMessage.stateUpdate(localState)

        do {
            let data = try JSONEncoder().encode(message)
            webSocket.send(data: data)
        } catch {
            print("Failed to encode state: \(error)")
        }
    }

    private func handleMessage(_ data: Data) {
        do {
            let message = try JSONDecoder().decode(SyncMessage.self, from: data)

            switch message {
            case .stateUpdate(let remoteState):
                mergeRemoteState(remoteState)

            case .cursorUpdate(let userID, let position):
                updateUserCursor(userID: userID, position: position)

            case .userJoined(let userID):
                users[userID] = RemoteUser(id: userID)

            case .userLeft(let userID):
                users.removeValue(forKey: userID)
            }
        } catch {
            print("Failed to decode message: \(error)")
        }
    }

    private func mergeRemoteState(_ remote: StrokeCRDT) {
        var merged = localState
        merged.merge(remote)
        localState = merged
    }

    private func updateUserCursor(userID: UUID, position: SIMD2<Float>) {
        users[userID]?.cursorPosition = position
    }
}

enum SyncMessage: Codable {
    case stateUpdate(StrokeCRDT)
    case cursorUpdate(UUID, CodableVector2)
    case userJoined(UUID)
    case userLeft(UUID)
}

struct RemoteUser {
    var id: UUID
    var cursorPosition: SIMD2<Float> = SIMD2(0, 0)
    var color: SIMD4<Float> = SIMD4(Float.random(in: 0...1),
                                    Float.random(in: 0...1),
                                    Float.random(in: 0...1),
                                    1.0)
}
```

**Sync Design**:
- **Broadcast on Change**: Every local edit sends full state (inefficient but simple)
- **CRDT Merge**: Incoming states merged with local state
- **Cursor Tracking**: Separate from CRDT (ephemeral data)

For production:
- Delta-based sync (send only changes)
- Compression (gzip JSON payloads)
- Batching (multiple edits in one message)

### Step 5: Canvas Renderer

`Rendering/CanvasRenderer.swift`:
```swift
import MetalKit

class CanvasRenderer: NSObject, MTKViewDelegate {
    var device: MTLDevice!
    var commandQueue: MTLCommandQueue!
    var pipelineState: MTLRenderPipelineState!

    var strokes: [Stroke] = []
    var strokeBuffers: [UUID: MTLBuffer] = [:]

    weak var metalView: MTKView?

    init(metalView: MTKView) {
        super.init()
        self.metalView = metalView
        setupMetal()
        createPipeline()
    }

    func setupMetal() {
        device = MTLCreateSystemDefaultDevice()
        commandQueue = device.makeCommandQueue()
    }

    func createPipeline() {
        let library = device.makeDefaultLibrary()
        let vertexFunction = library?.makeFunction(name: "stroke_vertex")
        let fragmentFunction = library?.makeFunction(name: "stroke_fragment")

        let descriptor = MTLRenderPipelineDescriptor()
        descriptor.vertexFunction = vertexFunction
        descriptor.fragmentFunction = fragmentFunction
        descriptor.colorAttachments[0].pixelFormat = .bgra8Unorm
        descriptor.colorAttachments[0].isBlendingEnabled = true
        descriptor.colorAttachments[0].rgbBlendOperation = .add
        descriptor.colorAttachments[0].sourceRGBBlendFactor = .sourceAlpha
        descriptor.colorAttachments[0].destinationRGBBlendFactor = .oneMinusSourceAlpha

        pipelineState = try! device.makeRenderPipelineState(descriptor: descriptor)
    }

    func updateStrokes(_ newStrokes: [Stroke]) {
        strokes = newStrokes

        // Create/update buffers for new strokes
        for stroke in strokes where strokeBuffers[stroke.id] == nil {
            createStrokeBuffer(stroke)
        }
    }

    private func createStrokeBuffer(_ stroke: Stroke) {
        // Convert stroke points to line segments (triangle strip)
        var vertices: [StrokeVertex] = []

        for i in 0..<stroke.points.count - 1 {
            let p1 = stroke.points[i]
            let p2 = stroke.points[i + 1]

            let dir = normalize(p2.position.simd - p1.position.simd)
            let normal = SIMD2<Float>(-dir.y, dir.x)

            let width = stroke.width * p1.pressure

            // Create quad (2 triangles) for line segment
            let v1 = StrokeVertex(
                position: p1.position.simd - normal * width * 0.5,
                color: stroke.color.simd
            )
            let v2 = StrokeVertex(
                position: p1.position.simd + normal * width * 0.5,
                color: stroke.color.simd
            )
            let v3 = StrokeVertex(
                position: p2.position.simd - normal * width * 0.5,
                color: stroke.color.simd
            )
            let v4 = StrokeVertex(
                position: p2.position.simd + normal * width * 0.5,
                color: stroke.color.simd
            )

            vertices.append(contentsOf: [v1, v2, v3, v3, v2, v4])
        }

        if !vertices.isEmpty {
            let size = vertices.count * MemoryLayout<StrokeVertex>.stride
            strokeBuffers[stroke.id] = device.makeBuffer(bytes: vertices, length: size, options: [])
        }
    }

    // MARK: - MTKViewDelegate

    func mtkView(_ view: MTKView, drawableSizeWillChange size: CGSize) {}

    func draw(in view: MTKView) {
        guard let drawable = view.currentDrawable,
              let descriptor = view.currentRenderPassDescriptor else { return }

        let commandBuffer = commandQueue.makeCommandBuffer()!
        let renderEncoder = commandBuffer.makeRenderCommandEncoder(descriptor: descriptor)!

        renderEncoder.setRenderPipelineState(pipelineState)

        // Draw all strokes
        for stroke in strokes {
            guard let buffer = strokeBuffers[stroke.id] else { continue }

            let vertexCount = buffer.length / MemoryLayout<StrokeVertex>.stride
            renderEncoder.setVertexBuffer(buffer, offset: 0, index: 0)
            renderEncoder.drawPrimitives(type: .triangle, vertexStart: 0, vertexCount: vertexCount)
        }

        renderEncoder.endEncoding()
        commandBuffer.present(drawable)
        commandBuffer.commit()
    }
}

struct StrokeVertex {
    var position: SIMD2<Float>
    var color: SIMD4<Float>
}
```

**Rendering Approach**:
- Convert polyline to triangle strip (quads with variable width)
- One buffer per stroke (cached, only rebuild on new stroke)
- Simple shader (no antialiasing, but fast)

For better quality:
- Distance field rendering (smooth curves)
- Catmull-Rom splines (smoother interpolation)
- Pressure-sensitive tapering

### Step 6: Stroke Shaders

`Rendering/StrokeShaders.metal`:
```metal
#include <metal_stdlib>
using namespace metal;

struct VertexIn {
    float2 position [[attribute(0)]];
    float4 color [[attribute(1)]];
};

struct VertexOut {
    float4 position [[position]];
    float4 color;
};

vertex VertexOut stroke_vertex(constant VertexIn* vertices [[buffer(0)]],
                               uint vid [[vertex_id]]) {
    VertexOut out;

    // Map canvas coordinates (0-1) to NDC (-1 to 1)
    float2 ndc = vertices[vid].position * 2.0 - 1.0;
    ndc.y = -ndc.y;  // Flip Y (canvas has top-left origin)

    out.position = float4(ndc, 0.0, 1.0);
    out.color = vertices[vid].color;

    return out;
}

fragment float4 stroke_fragment(VertexOut in [[stage_in]]) {
    return in.color;
}
```

Minimal shaders. Coordinates normalized to [0,1] (canvas space), converted to NDC for rendering.

### Step 7: Canvas View

`Views/CanvasView.swift`:
```swift
import SwiftUI
import MetalKit
import Combine

struct CanvasView: View {
    @StateObject private var syncEngine = SyncEngine(webSocket: WebSocketClient())
    @State private var currentColor: SIMD4<Float> = SIMD4(0, 0, 0, 1)
    @State private var brushSize: Float = 5.0

    var body: some View {
        VStack {
            ZStack {
                CanvasMetalView(
                    strokes: syncEngine.localState.visibleStrokes(),
                    onStrokeAdded: { stroke in
                        syncEngine.addStroke(stroke)
                    },
                    currentColor: $currentColor,
                    brushSize: $brushSize
                )

                // Show other users' cursors
                ForEach(Array(syncEngine.users.values), id: \.id) { user in
                    Circle()
                        .fill(Color(red: Double(user.color.x),
                                  green: Double(user.color.y),
                                  blue: Double(user.color.z)))
                        .frame(width: 20, height: 20)
                        .position(x: CGFloat(user.cursorPosition.x) * UIScreen.main.bounds.width,
                                y: CGFloat(user.cursorPosition.y) * UIScreen.main.bounds.height)
                }
            }

            ToolbarView(color: $currentColor, brushSize: $brushSize)
        }
        .onAppear {
            syncEngine.connect(to: URL(string: "ws://localhost:8080/sketch")!)
        }
    }
}

struct CanvasMetalView: UIViewRepresentable {
    let strokes: [Stroke]
    let onStrokeAdded: (Stroke) -> Void
    @Binding var currentColor: SIMD4<Float>
    @Binding var brushSize: Float

    func makeCoordinator() -> Coordinator {
        Coordinator(onStrokeAdded: onStrokeAdded)
    }

    func makeUIView(context: Context) -> MTKView {
        let metalView = MTKView()
        metalView.device = MTLCreateSystemDefaultDevice()
        metalView.delegate = context.coordinator.renderer
        metalView.clearColor = MTLClearColor(red: 1, green: 1, blue: 1, alpha: 1)
        metalView.colorPixelFormat = .bgra8Unorm

        context.coordinator.renderer.metalView = metalView
        context.coordinator.metalView = metalView
        context.coordinator.currentColor = currentColor
        context.coordinator.brushSize = brushSize

        let panGesture = UIPanGestureRecognizer(
            target: context.coordinator,
            action: #selector(Coordinator.handlePan(_:))
        )
        metalView.addGestureRecognizer(panGesture)

        return metalView
    }

    func updateUIView(_ uiView: MTKView, context: Context) {
        context.coordinator.renderer.updateStrokes(strokes)
        context.coordinator.currentColor = currentColor
        context.coordinator.brushSize = brushSize
    }

    class Coordinator: NSObject {
        let renderer: CanvasRenderer
        let onStrokeAdded: (Stroke) -> Void

        var metalView: MTKView?
        var currentStroke: Stroke?
        var currentColor: SIMD4<Float> = SIMD4(0, 0, 0, 1)
        var brushSize: Float = 5.0

        init(onStrokeAdded: @escaping (Stroke) -> Void) {
            self.onStrokeAdded = onStrokeAdded
            self.renderer = CanvasRenderer(metalView: MTKView())
        }

        @objc func handlePan(_ gesture: UIPanGestureRecognizer) {
            guard let view = gesture.view else { return }

            let location = gesture.location(in: view)
            let normalizedPos = SIMD2<Float>(
                Float(location.x / view.bounds.width),
                Float(location.y / view.bounds.height)
            )

            let pressure: Float = 1.0  // iOS doesn't give pressure from UIGestureRecognizer
                                       // Use 3D Touch or Apple Pencil APIs for real pressure

            let point = StrokePoint(
                position: CodableVector2(normalizedPos),
                pressure: pressure,
                timestamp: Clock.now()
            )

            switch gesture.state {
            case .began:
                currentStroke = Stroke(
                    id: UUID(),
                    points: [point],
                    color: CodableColor(currentColor),
                    width: brushSize / 100.0,
                    ownerID: Device.id,
                    createdAt: Clock.now()
                )

            case .changed:
                currentStroke?.points.append(point)

            case .ended, .cancelled:
                if let stroke = currentStroke {
                    onStrokeAdded(stroke)
                }
                currentStroke = nil

            default:
                break
            }
        }
    }
}
```

**Touch Handling**:
- Pan gesture tracks drawing
- Points collected during gesture
- On end, complete stroke added to CRDT and broadcast
- Coordinator pattern bridges UIKit gestures with SwiftUI

Python equivalent would need manual event loop management - Swift's gesture recognizers handle this cleanly.

## Common Pitfalls

### 1. CRDT Monotonicity Violations

```swift
// BAD: Using wall-clock time
timestamp = UInt64(Date().timeIntervalSince1970)
```

Clock skew between devices breaks ordering. Use logical clocks or hybrid logical clocks (HLC).

### 2. Unbounded Growth

CRDTs never delete data (tombstones persist forever). For long-running apps:
```swift
// Garbage collection: Remove old tombstones
if deletedStrokes.count > 10000 {
    let recent = deletedStrokes.sorted().suffix(5000)
    deletedStrokes = Set(recent)
}
```

Requires coordination to ensure all replicas have seen deleted items.

### 3. Network Partition Handling

What happens if client disconnects for 10 minutes? On reconnect:
```swift
// Send full state, merge with server
// Server responds with its state, client merges
```

CRDT guarantees eventual consistency, but large state transfers are expensive. Use delta-based sync or version vectors to minimize data.

### 4. Performance with Many Strokes

10,000 strokes = 10,000 buffers. Drawing slows down. Solutions:
- Merge old strokes into single buffer (loses individual editability)
- Spatial partitioning (only render visible strokes)
- Level-of-detail (simplify distant strokes)

### 5. Undo/Redo Semantics

Traditional undo/redo doesn't work with CRDTs:
- User A draws stroke 1
- User B draws stroke 2
- User A undos stroke 1
- What happens on B's screen?

Need intention-preserving undo (complex) or per-user undo stacks (simpler but less intuitive).

## Performance Notes

**CRDT Merge**: O(n) where n = number of strokes. With 1000 strokes: ~0.1ms.

**Network Bandwidth**: Full state sync for 1000 strokes ≈ 500KB. At 60fps, that's 30 MB/s - impractical. Use delta-based sync:
- Only send strokes added since last sync
- Reduces bandwidth by 100-1000×

**Rendering**: 1000 strokes, 50 points each = 50,000 triangles. Renders in <2ms on modern GPU.

CRDTs enable this without complex server logic - the math handles conflicts.
