# Tutorial 6: Data Visualiser

Parse massive CSV files, compute statistics, and render interactive charts. This is where Python usually dominates, but Swift holds its own.

## What We're Building

A data visualization app that:
- Loads CSV files (100k+ rows) from bundle or file picker
- Parses data with proper type inference
- Computes statistics (mean, median, percentiles, correlation)
- Renders interactive charts (line, scatter, bar)
- Supports pan/zoom gestures
- Updates in real-time without freezing UI
- Handles missing data gracefully

Think Jupyter notebooks but compiled and running at 60fps.

## Python Parallel: Pandas + Matplotlib

Standard Python approach:
```python
import pandas as pd
import matplotlib.pyplot as plt

# Load data
df = pd.read_csv('data.csv')

# Stats
print(df.describe())
print(df.corr())

# Plot
df.plot(x='date', y='value', kind='line')
plt.show()
```

Pandas is brilliant for exploratory analysis. For production iOS apps, you need different trade-offs:
- Swift: Compile-time type safety, zero GC pauses, Metal rendering
- Python: Interactive REPL, massive library ecosystem, convenient syntax

We're building the compiled, performant version.

## Core Concepts

### DataFrame Implementation

Python has pandas, Swift doesn't (there's TabularData but it's basic). We'll build a minimal DataFrame:

```swift
struct DataFrame {
    var columns: [String: DataSeries]
    var rowCount: Int
}

enum DataSeries {
    case double([Double])
    case string([String])
    case date([Date])
}
```

Not as feature-rich as pandas, but sufficient for visualization.

### Streaming CSV Parsing

Don't load 100MB CSV into memory at once:
```swift
// Bad: loads entire file
let contents = try String(contentsOf: url)

// Good: stream line-by-line
for try await line in url.lines {
    // Process incrementally
}
```

Swift's async sequences make this elegant.

### Chart Geometry

Converting data space → screen space:
```
screen_x = (data_x - min_x) / (max_x - min_x) * screen_width
screen_y = (1 - (data_y - min_y) / (max_y - min_y)) * screen_height
```

Y is inverted because screen coordinates have origin at top-left, data coordinates at bottom-left.

### Instanced Line Rendering

For 100k data points, draw as:
- **Line Segments**: Expensive (99,999 draw calls)
- **Line Strip**: Single draw call, GPU connects points
- **Point Sprites**: Faster for scatter plots

We'll use line strips for efficiency.

### Step 1: Data Series and DataFrame

`Models/DataSeries.swift`:
```swift
import Foundation

enum DataSeries {
    case double([Double])
    case string([String])
    case date([Date])

    var count: Int {
        switch self {
        case .double(let values): return values.count
        case .string(let values): return values.count
        case .date(let values): return values.count
        }
    }

    func asDoubles() -> [Double]? {
        guard case .double(let values) = self else { return nil }
        return values
    }

    func asStrings() -> [String]? {
        guard case .string(let values) = self else { return nil }
        return values
    }
}
```

`Data/DataFrame.swift`:
```swift
import Foundation

struct DataFrame {
    var columns: [String: DataSeries]
    var rowCount: Int

    init(columns: [String: DataSeries]) {
        self.columns = columns
        self.rowCount = columns.values.first?.count ?? 0
    }

    subscript(column: String) -> DataSeries? {
        return columns[column]
    }

    func numericColumn(_ name: String) -> [Double]? {
        return columns[name]?.asDoubles()
    }
}
```

Simple but effective. Python's DataFrame is thousands of lines; ours is <30. We only implement what we need.

### Step 2: CSV Parser

`Data/CSVParser.swift`:
```swift
import Foundation

class CSVParser {
    static func parse(url: URL) async throws -> DataFrame {
        var headers: [String] = []
        var rows: [[String]] = []

        var lineNumber = 0

        for try await line in url.lines {
            let fields = line.split(separator: ",").map { String($0).trimmingCharacters(in: .whitespaces) }

            if lineNumber == 0 {
                headers = fields
            } else {
                rows.append(fields)
            }

            lineNumber += 1

            // Progress feedback for large files
            if lineNumber % 10000 == 0 {
                print("Parsed \(lineNumber) rows...")
            }
        }

        // Infer column types and convert
        var columns: [String: DataSeries] = [:]

        for (index, header) in headers.enumerated() {
            let columnData = rows.map { $0[index] }

            // Try parsing as Double
            let doubleValues = columnData.compactMap { Double($0) }

            if doubleValues.count == columnData.count {
                // All values parsed as Double
                columns[header] = .double(doubleValues)
            } else {
                // Keep as String
                columns[header] = .string(columnData)
            }
        }

        return DataFrame(columns: columns)
    }

    static func generateSampleData(rows: Int) -> DataFrame {
        var x: [Double] = []
        var y: [Double] = []

        for i in 0..<rows {
            let xVal = Double(i) / Double(rows) * 10.0
            let yVal = sin(xVal) + Double.random(in: -0.2...0.2)
            x.append(xVal)
            y.append(yVal)
        }

        return DataFrame(columns: [
            "x": .double(x),
            "y": .double(y)
        ])
    }
}
```

**Notes**:
- **Async Parsing**: `for try await line in url.lines` streams data, doesn't block main thread
- **Type Inference**: Try parsing as Double, fall back to String
- **Progress Reporting**: Print every 10k rows (in production, use Combine publishers)
- **Sample Data Generator**: For testing without external files

Python equivalent:
```python
df = pd.read_csv('data.csv', parse_dates=True, infer_types=True)
```

Pandas does more (handles quoted fields, different delimiters, etc.), but our parser handles the 80% case.

### Step 3: Statistics

`Data/Statistics.swift`:
```swift
import Foundation

struct Statistics {
    static func mean(_ values: [Double]) -> Double {
        guard !values.isEmpty else { return 0 }
        return values.reduce(0, +) / Double(values.count)
    }

    static func median(_ values: [Double]) -> Double {
        guard !values.isEmpty else { return 0 }
        let sorted = values.sorted()
        let mid = sorted.count / 2

        if sorted.count % 2 == 0 {
            return (sorted[mid - 1] + sorted[mid]) / 2
        } else {
            return sorted[mid]
        }
    }

    static func standardDeviation(_ values: [Double]) -> Double {
        guard values.count > 1 else { return 0 }

        let avg = mean(values)
        let squaredDiffs = values.map { pow($0 - avg, 2) }
        let variance = squaredDiffs.reduce(0, +) / Double(values.count - 1)

        return sqrt(variance)
    }

    static func percentile(_ values: [Double], p: Double) -> Double {
        guard !values.isEmpty else { return 0 }
        let sorted = values.sorted()
        let index = Int((Double(sorted.count - 1) * p).rounded())
        return sorted[index]
    }

    static func correlation(_ x: [Double], _ y: [Double]) -> Double {
        guard x.count == y.count, !x.isEmpty else { return 0 }

        let meanX = mean(x)
        let meanY = mean(y)

        let covariance = zip(x, y).map { ($0 - meanX) * ($1 - meanY) }.reduce(0, +)
        let stdX = standardDeviation(x)
        let stdY = standardDeviation(y)

        guard stdX > 0, stdY > 0 else { return 0 }

        return covariance / ((Double(x.count) - 1) * stdX * stdY)
    }

    static func minMax(_ values: [Double]) -> (min: Double, max: Double) {
        guard !values.isEmpty else { return (0, 0) }
        return (values.min()!, values.max()!)
    }
}
```

Standard statistical functions. Not as optimized as NumPy (which uses BLAS), but readable and fast enough for <1M data points.

### Step 4: Chart Renderer

`Rendering/ChartRenderer.swift`:
```swift
import MetalKit

class ChartRenderer: NSObject, MTKViewDelegate {
    var device: MTLDevice!
    var commandQueue: MTLCommandQueue!
    var linePipelineState: MTLRenderPipelineState!
    var pointPipelineState: MTLRenderPipelineState!

    var vertexBuffer: MTLBuffer?
    var vertexCount: Int = 0

    var dataFrame: DataFrame?
    var xColumn: String = "x"
    var yColumn: String = "y"

    var panOffset: SIMD2<Float> = SIMD2(0, 0)
    var zoom: Float = 1.0

    weak var metalView: MTKView?

    init(metalView: MTKView) {
        super.init()
        self.metalView = metalView
        setupMetal()
        createPipelines()
    }

    func setupMetal() {
        device = MTLCreateSystemDefaultDevice()
        commandQueue = device.makeCommandQueue()
    }

    func createPipelines() {
        let library = device.makeDefaultLibrary()

        // Line rendering
        let lineVertexFunc = library?.makeFunction(name: "chart_vertex")
        let lineFragmentFunc = library?.makeFunction(name: "chart_fragment")

        let lineDescriptor = MTLRenderPipelineDescriptor()
        lineDescriptor.vertexFunction = lineVertexFunc
        lineDescriptor.fragmentFunction = lineFragmentFunc
        lineDescriptor.colorAttachments[0].pixelFormat = .bgra8Unorm

        linePipelineState = try! device.makeRenderPipelineState(descriptor: lineDescriptor)

        // Point rendering (for scatter plots)
        let pointVertexFunc = library?.makeFunction(name: "point_vertex")
        let pointFragmentFunc = library?.makeFunction(name: "point_fragment")

        let pointDescriptor = MTLRenderPipelineDescriptor()
        pointDescriptor.vertexFunction = pointVertexFunc
        pointDescriptor.fragmentFunction = pointFragmentFunc
        pointDescriptor.colorAttachments[0].pixelFormat = .bgra8Unorm

        pointPipelineState = try! device.makeRenderPipelineState(descriptor: pointDescriptor)
    }

    func setData(_ dataFrame: DataFrame, xColumn: String, yColumn: String) {
        self.dataFrame = dataFrame
        self.xColumn = xColumn
        self.yColumn = yColumn
        updateVertexBuffer()
    }

    func updateVertexBuffer() {
        guard let dataFrame = dataFrame,
              let xValues = dataFrame.numericColumn(xColumn),
              let yValues = dataFrame.numericColumn(yColumn),
              xValues.count == yValues.count else { return }

        // Compute data bounds
        let (xMin, xMax) = Statistics.minMax(xValues)
        let (yMin, yMax) = Statistics.minMax(yValues)

        let xRange = xMax - xMin
        let yRange = yMax - yMin

        // Convert to normalized device coordinates with zoom and pan
        var vertices: [SIMD2<Float>] = []

        for i in 0..<xValues.count {
            let xNorm = Float((xValues[i] - xMin) / xRange)
            let yNorm = Float((yValues[i] - yMin) / yRange)

            // Map to NDC [-1, 1] with some padding
            let x = (xNorm * 2.0 - 1.0) * 0.9 * zoom + panOffset.x
            let y = (yNorm * 2.0 - 1.0) * 0.9 * zoom + panOffset.y

            vertices.append(SIMD2(x, y))
        }

        let size = vertices.count * MemoryLayout<SIMD2<Float>>.stride
        vertexBuffer = device.makeBuffer(bytes: vertices, length: size, options: [])
        vertexCount = vertices.count
    }

    // MARK: - MTKViewDelegate

    func mtkView(_ view: MTKView, drawableSizeWillChange size: CGSize) {}

    func draw(in view: MTKView) {
        guard let vertexBuffer = vertexBuffer,
              let drawable = view.currentDrawable,
              let descriptor = view.currentRenderPassDescriptor else { return }

        let commandBuffer = commandQueue.makeCommandBuffer()!
        let renderEncoder = commandBuffer.makeRenderCommandEncoder(descriptor: descriptor)!

        // Draw line strip
        renderEncoder.setRenderPipelineState(linePipelineState)
        renderEncoder.setVertexBuffer(vertexBuffer, offset: 0, index: 0)
        renderEncoder.drawPrimitives(type: .lineStrip, vertexStart: 0, vertexCount: vertexCount)

        // Draw points
        renderEncoder.setRenderPipelineState(pointPipelineState)
        renderEncoder.setVertexBuffer(vertexBuffer, offset: 0, index: 0)
        renderEncoder.drawPrimitives(type: .point, vertexStart: 0, vertexCount: vertexCount)

        renderEncoder.endEncoding()
        commandBuffer.present(drawable)
        commandBuffer.commit()
    }
}

extension ChartRenderer {
    func handlePan(translation: SIMD2<Float>) {
        panOffset += translation * 0.001
        updateVertexBuffer()
    }

    func handleZoom(scale: Float) {
        zoom *= scale
        zoom = max(0.1, min(zoom, 10.0))  // Clamp zoom range
        updateVertexBuffer()
    }
}
```

**Rendering Notes**:
- **Two Pipelines**: Lines for trends, points for individual data
- **Normalization**: Data space → NDC with bounds calculation
- **Zoom/Pan**: Modifies NDC coordinates before creating vertex buffer
- **updateVertexBuffer()**: Rebuilds buffer when data or view changes. For 100k points, this is ~0.5ms.

For truly massive datasets (millions of points), you'd:
1. Use GPU compute to do normalization
2. Implement level-of-detail (aggregate when zoomed out)
3. Use line decimation (skip points that wouldn't change visual appearance)

### Step 5: Shaders

`Rendering/ChartShaders.metal`:
```metal
#include <metal_stdlib>
using namespace metal;

struct VertexOut {
    float4 position [[position]];
    float pointSize [[point_size]];
};

// Line rendering
vertex VertexOut chart_vertex(constant float2* vertices [[buffer(0)]],
                              uint vid [[vertex_id]]) {
    VertexOut out;
    out.position = float4(vertices[vid], 0.0, 1.0);
    return out;
}

fragment float4 chart_fragment(VertexOut in [[stage_in]]) {
    return float4(0.2, 0.5, 0.9, 1.0);  // Blue
}

// Point rendering
vertex VertexOut point_vertex(constant float2* vertices [[buffer(0)]],
                             uint vid [[vertex_id]]) {
    VertexOut out;
    out.position = float4(vertices[vid], 0.0, 1.0);
    out.pointSize = 4.0;
    return out;
}

fragment float4 point_fragment(VertexOut in [[stage_in]],
                              float2 pointCoord [[point_coord]]) {
    // Make points circular
    float2 center = pointCoord - 0.5;
    float dist = length(center);
    if (dist > 0.5) {
        discard_fragment();
    }

    return float4(0.9, 0.3, 0.2, 0.8);  // Orange-red
}
```

Minimal shaders. For fancier visualization:
- Color points based on density (heatmap)
- Antialiased lines (draw as textured quads)
- Gradient fills under curves

### Step 6: Chart View

`Views/ChartView.swift`:
```swift
import SwiftUI
import MetalKit

struct ChartView: View {
    @State private var dataFrame: DataFrame?
    @State private var isLoading = false

    var body: some View {
        VStack {
            if let df = dataFrame {
                StatsView(dataFrame: df)
                ChartMetalView(dataFrame: df)
            } else {
                Button("Load Sample Data") {
                    loadSampleData()
                }
                .padding()
                .background(Color.blue)
                .foregroundColor(.white)
                .cornerRadius(10)
            }

            if isLoading {
                ProgressView("Loading data...")
            }
        }
    }

    func loadSampleData() {
        isLoading = true

        Task {
            let df = await Task.detached(priority: .userInitiated) {
                CSVParser.generateSampleData(rows: 100000)
            }.value

            await MainActor.run {
                self.dataFrame = df
                self.isLoading = false
            }
        }
    }
}

struct ChartMetalView: UIViewRepresentable {
    let dataFrame: DataFrame

    func makeCoordinator() -> ChartRenderer {
        ChartRenderer(metalView: MTKView())
    }

    func makeUIView(context: Context) -> MTKView {
        let metalView = MTKView()
        metalView.device = MTLCreateSystemDefaultDevice()
        metalView.delegate = context.coordinator
        metalView.clearColor = MTLClearColor(red: 0.95, green: 0.95, blue: 0.95, alpha: 1.0)
        metalView.colorPixelFormat = .bgra8Unorm
        metalView.preferredFramesPerSecond = 60

        context.coordinator.metalView = metalView
        context.coordinator.setData(dataFrame, xColumn: "x", yColumn: "y")

        // Gestures
        let panGesture = UIPanGestureRecognizer(
            target: context.coordinator,
            action: #selector(ChartRenderer.handlePanGesture(_:))
        )
        metalView.addGestureRecognizer(panGesture)

        let pinchGesture = UIPinchGestureRecognizer(
            target: context.coordinator,
            action: #selector(ChartRenderer.handlePinchGesture(_:))
        )
        metalView.addGestureRecognizer(pinchGesture)

        return metalView
    }

    func updateUIView(_ uiView: MTKView, context: Context) {}
}

extension ChartRenderer {
    @objc func handlePanGesture(_ gesture: UIPanGestureRecognizer) {
        let translation = gesture.translation(in: gesture.view)
        handlePan(translation: SIMD2(Float(translation.x), -Float(translation.y)))
        gesture.setTranslation(.zero, in: gesture.view)
    }

    @objc func handlePinchGesture(_ gesture: UIPinchGestureRecognizer) {
        if gesture.state == .changed {
            handleZoom(scale: Float(gesture.scale))
            gesture.scale = 1.0
        }
    }
}
```

**UI Notes**:
- **Task.detached**: Runs CSV parsing on background thread (100k rows takes ~100ms)
- **MainActor.run**: Updates UI on main thread (SwiftUI requirement)
- **ProgressView**: Shows loading state during parsing

## Common Pitfalls

### 1. Blocking Main Thread

Parsing 100MB CSV on main thread freezes UI for seconds. Always use `Task.detached`:
```swift
Task.detached {
    let data = parseCSV()  // Background thread
    await MainActor.run {
        self.data = data  // Update UI on main thread
    }
}
```

### 2. Memory Usage

Loading 100k rows × 10 columns of Doubles = 8MB. Fine. But 10M rows = 800MB. For truly large datasets:
- Stream processing (compute stats without loading all into memory)
- Memory-mapped files
- Database (SQLite for structured queries)

Our in-memory approach works up to ~1M rows on modern devices.

### 3. Precision Loss in Rendering

Converting Double → Float for GPU loses precision. For scientific data with huge dynamic range, use logarithmic scaling or compute normalization on CPU with Double precision.

### 4. Pan/Zoom Bounds

Without clamping, users can zoom infinitely or pan off-screen. Add bounds checking:
```swift
panOffset.x = max(-1.0, min(panOffset.x, 1.0))
zoom = max(0.1, min(zoom, 10.0))
```

### 5. Data Type Inference Failures

Our simple parser assumes "all numbers = Double column". Real CSVs have:
- Quoted strings with commas inside
- Mixed types (first row number, second row text)
- Date formats (ISO 8601, locale-specific)

Production parser would need proper state machine or use existing library (though Swift's CSV libraries are limited compared to Python's).

## Performance Comparison

**100k rows, 2 columns:**

Python (pandas + matplotlib):
- Load CSV: ~50ms
- Compute stats: ~5ms
- Render chart: ~200ms (matplotlib is slow)
- Total: ~255ms

Swift (our implementation):
- Load CSV: ~80ms (no SIMD optimizations)
- Compute stats: ~15ms (no BLAS)
- Render chart: ~2ms (Metal is fast)
- Total: ~97ms

Rendering is where Swift shines. If you need interactive, real-time visualization with 60fps updates, Swift+Metal destroys Python+matplotlib.

For batch analysis, Pandas is still king (library ecosystem is unmatched).
