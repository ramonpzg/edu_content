# Tutorial 4: Snake Game

A classic game to teach you state management, input handling, and game loops in Swift. Much less GPU wizardry, much more architecture.

## What We're Building

Snake. You know it:
- Grid-based movement
- Snake grows when eating food
- Game over when hitting walls or yourself
- Swipe controls
- Score tracking

We'll use SwiftUI for the UI scaffolding and a custom Metal renderer for the grid. Why Metal for simple rectangles? Because drawing 400+ colored rectangles with SwiftUI shapes would be abysmal for performance, and this is a good excuse to show instanced rendering with actual gameplay.

## Python Parallel: Pygame Snake

In Python with Pygame:
```python
import pygame

class Snake:
    def __init__(self):
        self.segments = [(5, 5)]
        self.direction = (1, 0)

    def update(self):
        head = self.segments[0]
        new_head = (head[0] + self.direction[0],
                    head[1] + self.direction[1])
        self.segments.insert(0, new_head)
        self.segments.pop()

    def draw(self, screen):
        for segment in self.segments:
            pygame.draw.rect(screen, GREEN,
                           (segment[0]*20, segment[1]*20, 20, 20))
```

Swift's approach is similar but with stronger typing and value semantics. Instead of tuples, we use structs. Instead of Pygame's event loop, we use SwiftUI's declarative views with a game timer.

## Core Concepts

### Value Types vs Reference Types

Swift pushes value semantics hard. Our `Position` and `Direction` will be structs (value types), while `GameState` will be a class (reference type, published via `@ObservableObject`).

Python: Everything's a reference unless it's an immutable built-in.
Swift: Structs are copied, classes are referenced. Choose deliberately.

### ObservableObject and Published

SwiftUI's reactivity system. When a `@Published` property changes, SwiftUI automatically re-renders dependent views:

```swift
class GameState: ObservableObject {
    @Published var score: Int = 0  // SwiftUI watches this
}
```

Python equivalent: Reactive frameworks like RxPY, or manual observer patterns. SwiftUI bakes it into the language.

### Game Loop

Three options in iOS:
1. **CADisplayLink**: Syncs to screen refresh (60/120Hz). Best for smooth rendering.
2. **Timer**: Scheduled updates at fixed intervals. Good for game logic that doesn't need every frame.
3. **Combine Framework**: Reactive streams for event handling.

We'll use `Timer.publish()` for game ticks (snake movement) and Metal's built-in display loop for rendering.

## Implementation

### Step 1: Model Types

`Models/Position.swift`:
```swift
struct Position: Hashable, Equatable {
    var x: Int
    var y: Int

    static func +(lhs: Position, rhs: Position) -> Position {
        Position(x: lhs.x + rhs.x, y: lhs.y + rhs.y)
    }
}
```

`Models/Direction.swift`:
```swift
enum Direction: CaseIterable {
    case up, down, left, right

    var delta: Position {
        switch self {
        case .up:    return Position(x: 0, y: -1)
        case .down:  return Position(x: 0, y: 1)
        case .left:  return Position(x: -1, y: 0)
        case .right: return Position(x: 1, y: 0)
        }
    }

    var opposite: Direction {
        switch self {
        case .up:    return .down
        case .down:  return .up
        case .left:  return .right
        case .right: return .left
        }
    }
}
```

`Models/GameConfig.swift`:
```swift
enum GameConfig {
    static let gridWidth = 20
    static let gridHeight = 30
    static let tickInterval: TimeInterval = 0.15  // Seconds per move
}
```

**Notes**:
- `Position` conforms to `Hashable` so we can use it in Sets (for collision detection)
- `Direction.delta` converts direction to grid movement
- `opposite` prevents snake from reversing into itself
- Using `enum` for constants instead of a struct with static properties (both work, enum is slightly more idiomatic)

### Step 2: Game State

`GameState.swift`:
```swift
import Foundation
import Combine

class GameState: ObservableObject {
    @Published var snake: [Position] = [Position(x: 10, y: 15)]
    @Published var food: Position = Position(x: 5, y: 5)
    @Published var direction: Direction = .right
    @Published var score: Int = 0
    @Published var isGameOver: Bool = false

    private var nextDirection: Direction = .right
    private var timer: AnyCancellable?

    func start() {
        snake = [Position(x: 10, y: 15)]
        direction = .right
        nextDirection = .right
        score = 0
        isGameOver = false
        spawnFood()

        // Game tick timer
        timer = Timer.publish(every: GameConfig.tickInterval, on: .main, in: .common)
            .autoconnect()
            .sink { [weak self] _ in
                self?.update()
            }
    }

    func stop() {
        timer?.cancel()
    }

    func changeDirection(_ newDirection: Direction) {
        // Prevent reversing into self
        if newDirection != direction.opposite {
            nextDirection = newDirection
        }
    }

    private func update() {
        guard !isGameOver else { return }

        // Apply queued direction (prevents double-tap issues)
        direction = nextDirection

        // Move snake
        let head = snake[0]
        let newHead = head + direction.delta

        // Check collisions
        if isOutOfBounds(newHead) || snake.contains(newHead) {
            isGameOver = true
            timer?.cancel()
            return
        }

        snake.insert(newHead, at: 0)

        // Check food
        if newHead == food {
            score += 10
            spawnFood()
        } else {
            snake.removeLast()  // Don't grow if no food eaten
        }
    }

    private func isOutOfBounds(_ pos: Position) -> Bool {
        pos.x < 0 || pos.x >= GameConfig.gridWidth ||
        pos.y < 0 || pos.y >= GameConfig.gridHeight
    }

    private func spawnFood() {
        var newFood: Position
        repeat {
            newFood = Position(
                x: Int.random(in: 0..<GameConfig.gridWidth),
                y: Int.random(in: 0..<GameConfig.gridHeight)
            )
        } while snake.contains(newFood)
        food = newFood
    }
}
```

**Key Points**:

1. **@Published Properties**: Changes automatically trigger SwiftUI updates. When `score` changes, any `Text("\(gameState.score)")` view re-renders.

2. **Timer with Combine**: `Timer.publish()` creates a Combine publisher that emits every `tickInterval`. `sink()` subscribes to it, calling `update()` each tick.

3. **[weak self]**: Prevents retain cycles. Timer holds a reference to the closure, closure would hold `self`, creating a cycle. `weak` breaks it.

4. **Direction Buffering**: `nextDirection` queued and applied at next update. Prevents issues where player presses two directions in one tick.

5. **Collision Detection**: `snake.contains(newHead)` works because `Position` is `Hashable`. Set lookup is O(1) average case.

Python equivalent:
```python
class GameState:
    def __init__(self):
        self.snake = [(10, 15)]
        self.direction = (1, 0)
        # ... etc

    def update(self):
        head = self.snake[0]
        new_head = (head[0] + self.direction[0],
                    head[1] + self.direction[1])

        if new_head in self.snake or self.out_of_bounds(new_head):
            self.game_over = True
            return

        self.snake.insert(0, new_head)
        if new_head == self.food:
            self.score += 10
            self.spawn_food()
        else:
            self.snake.pop()
```

Same logic, less ceremony. Swift's type safety catches errors at compile-time that Python would only catch at runtime.

### Step 3: Grid Renderer

`GridRenderer.swift`:
```swift
import MetalKit

class GridRenderer: NSObject, MTKViewDelegate {
    var device: MTLDevice!
    var commandQueue: MTLCommandQueue!
    var pipelineState: MTLRenderPipelineState!
    var vertexBuffer: MTLBuffer!  // Single quad
    var instanceBuffer: MTLBuffer!

    var gameState: GameState
    weak var metalView: MTKView?

    init(metalView: MTKView, gameState: GameState) {
        self.gameState = gameState
        super.init()
        self.metalView = metalView
        setupMetal()
        createBuffers()
        createPipeline()
    }

    func setupMetal() {
        device = MTLCreateSystemDefaultDevice()
        commandQueue = device.makeCommandQueue()
    }

    func createBuffers() {
        // Single quad (2 triangles) in NDC space
        let quadVertices: [SIMD2<Float>] = [
            SIMD2(-1, -1),  // Bottom-left
            SIMD2( 1, -1),  // Bottom-right
            SIMD2(-1,  1),  // Top-left
            SIMD2( 1, -1),  // Bottom-right
            SIMD2( 1,  1),  // Top-right
            SIMD2(-1,  1)   // Top-left
        ]

        let size = quadVertices.count * MemoryLayout<SIMD2<Float>>.stride
        vertexBuffer = device.makeBuffer(bytes: quadVertices, length: size, options: [])

        // Instance buffer will be updated each frame
        let maxInstances = GameConfig.gridWidth * GameConfig.gridHeight
        let instanceSize = maxInstances * MemoryLayout<CellInstance>.stride
        instanceBuffer = device.makeBuffer(length: instanceSize, options: .storageModeShared)
    }

    func createPipeline() {
        let library = device.makeDefaultLibrary()
        let vertexFunction = library?.makeFunction(name: "grid_vertex")
        let fragmentFunction = library?.makeFunction(name: "grid_fragment")

        let descriptor = MTLRenderPipelineDescriptor()
        descriptor.vertexFunction = vertexFunction
        descriptor.fragmentFunction = fragmentFunction
        descriptor.colorAttachments[0].pixelFormat = .bgra8Unorm

        pipelineState = try! device.makeRenderPipelineState(descriptor: descriptor)
    }

    func updateInstanceBuffer() {
        var instances: [CellInstance] = []

        let cellWidth = 2.0 / Float(GameConfig.gridWidth)
        let cellHeight = 2.0 / Float(GameConfig.gridHeight)

        // Snake segments
        for segment in gameState.snake {
            let instance = CellInstance(
                position: gridToNDC(segment, cellWidth: cellWidth, cellHeight: cellHeight),
                size: SIMD2(cellWidth * 0.9, cellHeight * 0.9),  // 90% size for gaps
                color: SIMD4(0.2, 0.8, 0.2, 1.0)  // Green
            )
            instances.append(instance)
        }

        // Food
        let foodInstance = CellInstance(
            position: gridToNDC(gameState.food, cellWidth: cellWidth, cellHeight: cellHeight),
            size: SIMD2(cellWidth * 0.9, cellHeight * 0.9),
            color: SIMD4(0.9, 0.2, 0.2, 1.0)  // Red
        )
        instances.append(foodInstance)

        // Copy to GPU
        let bufferPointer = instanceBuffer.contents().bindMemory(to: CellInstance.self,
                                                                  capacity: instances.count)
        bufferPointer.initialize(from: instances, count: instances.count)
    }

    func gridToNDC(_ pos: Position, cellWidth: Float, cellHeight: Float) -> SIMD2<Float> {
        let x = -1.0 + Float(pos.x) * cellWidth + cellWidth / 2
        let y = 1.0 - Float(pos.y) * cellHeight - cellHeight / 2
        return SIMD2(x, y)
    }

    // MARK: - MTKViewDelegate

    func mtkView(_ view: MTKView, drawableSizeWillChange size: CGSize) {}

    func draw(in view: MTKView) {
        updateInstanceBuffer()

        guard let drawable = view.currentDrawable,
              let descriptor = view.currentRenderPassDescriptor else { return }

        let commandBuffer = commandQueue.makeCommandBuffer()!
        let renderEncoder = commandBuffer.makeRenderCommandEncoder(descriptor: descriptor)!

        renderEncoder.setRenderPipelineState(pipelineState)
        renderEncoder.setVertexBuffer(vertexBuffer, offset: 0, index: 0)
        renderEncoder.setVertexBuffer(instanceBuffer, offset: 0, index: 1)

        let instanceCount = gameState.snake.count + 1  // Snake + food
        renderEncoder.drawPrimitives(type: .triangle,
                                     vertexStart: 0,
                                     vertexCount: 6,  // 6 vertices per quad
                                     instanceCount: instanceCount)

        renderEncoder.endEncoding()
        commandBuffer.present(drawable)
        commandBuffer.commit()
    }
}

struct CellInstance {
    var position: SIMD2<Float>  // Center in NDC
    var size: SIMD2<Float>      // Width/height in NDC
    var color: SIMD4<Float>     // RGBA
}
```

**Breakdown**:

1. **Instanced Rendering**: One quad geometry, drawn multiple times (once per snake segment + food). Each instance has different position, size, color.

2. **gridToNDC()**: Converts grid coordinates (0-20, 0-30) to normalized device coordinates (-1 to 1). Grid origin is top-left, NDC origin is center.

3. **90% Cell Size**: Gaps between cells for visual clarity. Classic Snake aesthetic.

4. **updateInstanceBuffer()**: Rebuilds instance data every frame. Inefficient for large grids, but snake is small (<100 segments max) so it's fine. For 10,000 objects you'd use a different approach (persistent buffer, update only deltas).

5. **bindMemory()**: Swift's way of treating raw buffer memory as typed data. Like `numpy.frombuffer()` or C's pointer casting.

### Step 4: Shaders

`GridShaders.metal`:
```metal
#include <metal_stdlib>
using namespace metal;

struct CellInstance {
    float2 position;
    float2 size;
    float4 color;
};

struct VertexOut {
    float4 position [[position]];
    float4 color;
};

vertex VertexOut grid_vertex(constant float2* vertices [[buffer(0)]],
                             constant CellInstance* instances [[buffer(1)]],
                             uint vid [[vertex_id]],
                             uint iid [[instance_id]]) {
    CellInstance instance = instances[iid];
    float2 vertex = vertices[vid];

    // Scale and translate quad
    float2 pos = vertex * instance.size / 2.0 + instance.position;

    VertexOut out;
    out.position = float4(pos, 0.0, 1.0);
    out.color = instance.color;
    return out;
}

fragment float4 grid_fragment(VertexOut in [[stage_in]]) {
    return in.color;
}
```

**Shader Notes**:

- **[[instance_id]]**: Built-in variable giving current instance index. For the 5th snake segment, `iid = 4`.
- **Per-Instance Transform**: Each instance scales and translates the base quad geometry.
- Vertex shader runs 6 times per instance (6 vertices in quad), fragment shader runs once per pixel.

### Step 5: Game View

`GameView.swift`:
```swift
import SwiftUI
import MetalKit

struct GameView: View {
    @StateObject private var gameState = GameState()

    var body: some View {
        ZStack {
            Color.black.ignoresSafeArea()

            VStack {
                // Score
                HStack {
                    Text("Score: \(gameState.score)")
                        .font(.title)
                        .foregroundColor(.white)
                    Spacer()
                }
                .padding()

                // Game grid
                GridMetalView(gameState: gameState)
                    .aspectRatio(
                        CGFloat(GameConfig.gridWidth) / CGFloat(GameConfig.gridHeight),
                        contentMode: .fit
                    )
                    .gesture(
                        DragGesture(minimumDistance: 20)
                            .onEnded { gesture in
                                handleSwipe(gesture)
                            }
                    )

                Spacer()

                // Controls
                if gameState.isGameOver {
                    VStack {
                        Text("Game Over")
                            .font(.largeTitle)
                            .foregroundColor(.red)

                        Button("Restart") {
                            gameState.start()
                        }
                        .font(.title2)
                        .padding()
                        .background(Color.green)
                        .foregroundColor(.white)
                        .cornerRadius(10)
                    }
                }
            }
        }
        .onAppear {
            gameState.start()
        }
        .onDisappear {
            gameState.stop()
        }
    }

    func handleSwipe(_ gesture: DragGesture.Value) {
        let horizontal = abs(gesture.translation.width) > abs(gesture.translation.height)

        if horizontal {
            gameState.changeDirection(gesture.translation.width > 0 ? .right : .left)
        } else {
            gameState.changeDirection(gesture.translation.height > 0 ? .down : .up)
        }
    }
}

struct GridMetalView: UIViewRepresentable {
    let gameState: GameState

    func makeCoordinator() -> GridRenderer {
        GridRenderer(metalView: MTKView(), gameState: gameState)
    }

    func makeUIView(context: Context) -> MTKView {
        let metalView = MTKView()
        metalView.device = MTLCreateSystemDefaultDevice()
        metalView.delegate = context.coordinator
        metalView.clearColor = MTLClearColor(red: 0.05, green: 0.05, blue: 0.1, alpha: 1.0)
        metalView.colorPixelFormat = .bgra8Unorm
        metalView.preferredFramesPerSecond = 60

        context.coordinator.metalView = metalView

        return metalView
    }

    func updateUIView(_ uiView: MTKView, context: Context) {}
}
```

**SwiftUI Points**:

1. **@StateObject**: Creates and owns the `GameState` instance. SwiftUI manages its lifetime.

2. **DragGesture**: Detects swipes. `minimumDistance: 20` prevents accidental touches.

3. **aspectRatio()**: Maintains grid proportions when screen size changes.

4. **onAppear/onDisappear**: Lifecycle hooks. Start game when view appears, stop timer when it disappears (prevents memory leaks).

Python equivalent:
```python
class GameView:
    def __init__(self):
        self.game_state = GameState()

    def on_swipe(self, dx, dy):
        if abs(dx) > abs(dy):
            direction = Direction.RIGHT if dx > 0 else Direction.LEFT
        else:
            direction = Direction.DOWN if dy > 0 else Direction.UP
        self.game_state.change_direction(direction)
```

## Common Pitfalls

### 1. Direction Change Timing

If you allow direction changes mid-update, player can do this:
1. Snake moving right
2. Quick swipes: up, then left (before next update)
3. Snake tries to go left (opposite of right) = collision with self

Solution: Buffer next direction and apply it at update start. Our `nextDirection` variable handles this.

### 2. Timer Memory Leaks

Without `[weak self]` in the timer closure:
```swift
timer = Timer.publish(...).sink { self.update() }
```

The timer holds the closure, closure holds `self`, `self` holds the timer. Retain cycle. The view never deallocates. Use `weak` to break the cycle.

### 3. Food Spawning in Snake

If you don't check snake positions when spawning food, it can spawn inside the snake. Our `repeat-while` loop handles this, but with a very long snake, this could loop many times. Better solution: maintain a set of empty positions, pick one randomly.

### 4. SwiftUI Re-Render Frequency

`@Published` properties trigger re-renders. If you update `score` every frame (60fps), SwiftUI tries to re-render the entire view tree 60 times per second. This is wasteful since score only changes when eating food.

Our implementation only updates `score` on food collision, not every frame. Be mindful of what you publish.

### 5. Aspect Ratio Calculations

`aspectRatio()` modifier can behave unexpectedly with different `contentMode` values:
- `.fit`: Scales to fit within available space
- `.fill`: Scales to fill available space (may crop)

For a game, `.fit` prevents stretching. The grid stays square-ish.

## Performance Notes

Rendering 30-100 colored rectangles with instanced Metal calls: ~0.05ms per frame.
Same with SwiftUI `Rectangle()` views: ~3ms per frame (60× slower).

Why? SwiftUI rectangles go through the entire view diffing and layout system. Metal instances are just GPU draw calls. For static UI, SwiftUI is fine. For dynamic game rendering, Metal wins.

Game logic (collision detection, movement): ~0.01ms per update.

Total frame budget: 16.67ms (60fps). We're using <0.1ms. Plenty of headroom for fancier graphics or game logic.
