# Swift for Python Developers

A 10-part series teaching Swift and iOS development from an advanced Python programmer's perspective. No fluff, no hand-holding, just proper engineering.

## What You'll Build

This isn't one of those "Hello World" affairs that leaves you wondering what actual apps look like. You'll build 10 progressively complex applications:

1. **Hello Triangle** - Metal graphics fundamentals. Drawing pixels directly.
2. **3D Spinning Cube** - Proper 3D with transforms, cameras, and maths.
3. **Particle System** - Thousands of particles, GPU compute shaders, performance.
4. **Snake Game** - Classic game logic with SwiftUI. Simple but solid.
5. **3D Scene Explorer** - Navigate a textured 3D world with gestures.
6. **Data Visualiser** - Parse 100k+ rows, render interactive charts, don't crash.
7. **AR Treasure Hunt** - ARKit game finding objects in physical space.
8. **AI Chatbot** - OpenAI API, SQLite persistence, proper async/await.
9. **Metal Shader Playground** - Write custom GPU shaders, real-time manipulation.
10. **Multiplayer Sketchpad** - CRDTs for conflict-free collaboration, WebSocket sync.

## Swift vs Python: The Essentials

Since you're coming from Python, here are the main conceptual shifts:

### Type System
Python: Duck typing, runtime type checks, mypy if you're fancy
Swift: Compile-time type checking, type inference, protocols with associated types

### Memory Management
Python: Reference counting + cycle detection, GC for cleanup
Swift: Automatic Reference Counting (ARC), no GC, explicit weak/unowned

### Concurrency
Python: GIL-limited threading, asyncio event loop, multiprocessing
Swift: Proper threading, structured concurrency with async/await, actors

### Syntax Philosophy
Python: "One obvious way to do it", whitespace matters, explicit > implicit
Swift: Multiple paradigms, braces everywhere, protocol-oriented + OOP + functional

You'll notice Swift feels closer to Rust than Python in many ways. That's not a bug.
