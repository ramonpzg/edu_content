# Tutorial 5: 3D Scene Explorer

Build a navigable 3D environment with textures, lighting, and gesture-based camera controls. No VR headset required, just drag to look around.

## What We're Building

A first-person 3D scene viewer:
- Room with textured floor, walls, and ceiling
- Multiple 3D objects (cubes, spheres, etc.) with textures
- Drag to rotate camera (look around)
- Pinch to zoom (move forward/backward)
- Basic directional lighting for depth perception
- Smooth gesture handling

Think museum exhibition viewer or architectural walkthrough, but less corporate and more "I want to understand how this actually works".

## Core Concepts

### Texture Mapping

Process:
1. Load image file (JPEG, PNG) into memory
2. Create `MTLTexture` from image data
3. Pass texture to fragment shader
4. Sample texture using UV coordinates

UV coordinates: 2D coordinates (u, v) in range [0, 1] that map vertices to texture pixels. A quad with UVs (0,0), (1,0), (1,1), (0,1) gets the full texture mapped onto it.

### Camera Control

First-person camera = position + orientation (pitch, yaw):
- **Pitch**: Rotation around X-axis (look up/down)
- **Yaw**: Rotation around Y-axis (look left/right)
- **Position**: 3D coordinates in world space

Pan gesture → change pitch/yaw
Pinch gesture → move position forward/backward

### Lighting Model

We'll implement basic diffuse lighting (Lambertian reflection):
```
color = texture_color * (ambient + diffuse * max(0, dot(normal, light_direction)))
```

- **Ambient**: Base lighting (so objects in shadow aren't completely black)
- **Diffuse**: Directional lighting based on surface normal
- **Normal**: Vector perpendicular to surface (defines "which way it faces")

This isn't physically accurate, but it looks decent and runs fast.

## Implementation

### Step 1: Texture Loading Utility

`Models/Texture.swift`:
```swift
import MetalKit

class TextureLoader {
    static func loadTexture(named name: String, device: MTLDevice) -> MTLTexture? {
        let textureLoader = MTKTextureLoader(device: device)

        guard let url = Bundle.main.url(forResource: name, withExtension: nil) else {
            print("Texture file not found: \(name)")
            return nil
        }

        do {
            let texture = try textureLoader.newTexture(URL: url, options: [
                .textureUsage: NSNumber(value: MTLTextureUsage.shaderRead.rawValue),
                .textureStorageMode: NSNumber(value: MTLStorageMode.private.rawValue),
                .SRGB: false
            ])
            return texture
        } catch {
            print("Failed to load texture: \(error)")
            return nil
        }
    }

    static func createSolidColorTexture(color: SIMD4<UInt8>, device: MTLDevice) -> MTLTexture? {
        let descriptor = MTLTextureDescriptor.texture2DDescriptor(
            pixelFormat: .rgba8Unorm,
            width: 1,
            height: 1,
            mipmapped: false
        )
        descriptor.usage = .shaderRead

        guard let texture = device.makeTexture(descriptor: descriptor) else {
            return nil
        }

        var pixel = color
        let region = MTLRegionMake2D(0, 0, 1, 1)
        texture.replace(region: region, mipmapLevel: 0, withBytes: &pixel, bytesPerRow: 4)

        return texture
    }
}
```

**Notes**:
- `MTKTextureLoader`: Convenience class for loading common image formats
- `.SRGB: false`: Skip gamma correction (we'll handle it in shader if needed)
- `.textureStorageMode: .private`: GPU-only memory, faster access
- `createSolidColorTexture()`: Fallback for missing textures or debug colors

### Step 2: Mesh Definition

`Models/Mesh.swift`:
```swift
import MetalKit

struct Vertex {
    var position: SIMD3<Float>
    var normal: SIMD3<Float>
    var texCoord: SIMD2<Float>
}

class Mesh {
    var vertexBuffer: MTLBuffer
    var indexBuffer: MTLBuffer
    var indexCount: Int

    init(vertices: [Vertex], indices: [UInt16], device: MTLDevice) {
        let vertexSize = vertices.count * MemoryLayout<Vertex>.stride
        vertexBuffer = device.makeBuffer(bytes: vertices, length: vertexSize, options: [])!

        let indexSize = indices.count * MemoryLayout<UInt16>.stride
        indexBuffer = device.makeBuffer(bytes: indices, length: indexSize, options: [])!

        indexCount = indices.count
    }

    static func createCube(size: Float, device: MTLDevice) -> Mesh {
        let s = size / 2

        // Cube vertices with normals and UVs
        let vertices: [Vertex] = [
            // Front face (Z+)
            Vertex(position: SIMD3(-s, -s,  s), normal: SIMD3(0, 0, 1), texCoord: SIMD2(0, 1)),
            Vertex(position: SIMD3( s, -s,  s), normal: SIMD3(0, 0, 1), texCoord: SIMD2(1, 1)),
            Vertex(position: SIMD3( s,  s,  s), normal: SIMD3(0, 0, 1), texCoord: SIMD2(1, 0)),
            Vertex(position: SIMD3(-s,  s,  s), normal: SIMD3(0, 0, 1), texCoord: SIMD2(0, 0)),

            // Back face (Z-)
            Vertex(position: SIMD3( s, -s, -s), normal: SIMD3(0, 0, -1), texCoord: SIMD2(0, 1)),
            Vertex(position: SIMD3(-s, -s, -s), normal: SIMD3(0, 0, -1), texCoord: SIMD2(1, 1)),
            Vertex(position: SIMD3(-s,  s, -s), normal: SIMD3(0, 0, -1), texCoord: SIMD2(1, 0)),
            Vertex(position: SIMD3( s,  s, -s), normal: SIMD3(0, 0, -1), texCoord: SIMD2(0, 0)),

            // Left face (X-)
            Vertex(position: SIMD3(-s, -s, -s), normal: SIMD3(-1, 0, 0), texCoord: SIMD2(0, 1)),
            Vertex(position: SIMD3(-s, -s,  s), normal: SIMD3(-1, 0, 0), texCoord: SIMD2(1, 1)),
            Vertex(position: SIMD3(-s,  s,  s), normal: SIMD3(-1, 0, 0), texCoord: SIMD2(1, 0)),
            Vertex(position: SIMD3(-s,  s, -s), normal: SIMD3(-1, 0, 0), texCoord: SIMD2(0, 0)),

            // Right face (X+)
            Vertex(position: SIMD3( s, -s,  s), normal: SIMD3(1, 0, 0), texCoord: SIMD2(0, 1)),
            Vertex(position: SIMD3( s, -s, -s), normal: SIMD3(1, 0, 0), texCoord: SIMD2(1, 1)),
            Vertex(position: SIMD3( s,  s, -s), normal: SIMD3(1, 0, 0), texCoord: SIMD2(1, 0)),
            Vertex(position: SIMD3( s,  s,  s), normal: SIMD3(1, 0, 0), texCoord: SIMD2(0, 0)),

            // Top face (Y+)
            Vertex(position: SIMD3(-s,  s,  s), normal: SIMD3(0, 1, 0), texCoord: SIMD2(0, 1)),
            Vertex(position: SIMD3( s,  s,  s), normal: SIMD3(0, 1, 0), texCoord: SIMD2(1, 1)),
            Vertex(position: SIMD3( s,  s, -s), normal: SIMD3(0, 1, 0), texCoord: SIMD2(1, 0)),
            Vertex(position: SIMD3(-s,  s, -s), normal: SIMD3(0, 1, 0), texCoord: SIMD2(0, 0)),

            // Bottom face (Y-)
            Vertex(position: SIMD3(-s, -s, -s), normal: SIMD3(0, -1, 0), texCoord: SIMD2(0, 1)),
            Vertex(position: SIMD3( s, -s, -s), normal: SIMD3(0, -1, 0), texCoord: SIMD2(1, 1)),
            Vertex(position: SIMD3( s, -s,  s), normal: SIMD3(0, -1, 0), texCoord: SIMD2(1, 0)),
            Vertex(position: SIMD3(-s, -s,  s), normal: SIMD3(0, -1, 0), texCoord: SIMD2(0, 0))
        ]

        let indices: [UInt16] = [
            0, 1, 2,  2, 3, 0,    // Front
            4, 5, 6,  6, 7, 4,    // Back
            8, 9, 10,  10, 11, 8, // Left
            12, 13, 14,  14, 15, 12, // Right
            16, 17, 18,  18, 19, 16, // Top
            20, 21, 22,  22, 23, 20  // Bottom
        ]

        return Mesh(vertices: vertices, indices: indices, device: device)
    }

    static func createPlane(width: Float, height: Float, device: MTLDevice) -> Mesh {
        let w = width / 2
        let h = height / 2

        let vertices: [Vertex] = [
            Vertex(position: SIMD3(-w, 0, -h), normal: SIMD3(0, 1, 0), texCoord: SIMD2(0, 0)),
            Vertex(position: SIMD3( w, 0, -h), normal: SIMD3(0, 1, 0), texCoord: SIMD2(1, 0)),
            Vertex(position: SIMD3( w, 0,  h), normal: SIMD3(0, 1, 0), texCoord: SIMD2(1, 1)),
            Vertex(position: SIMD3(-w, 0,  h), normal: SIMD3(0, 1, 0), texCoord: SIMD2(0, 1))
        ]

        let indices: [UInt16] = [0, 1, 2,  2, 3, 0]

        return Mesh(vertices: vertices, indices: indices, device: device)
    }
}
```

**Notes**:
- Each face has its own vertices (even though corners are shared) because normals differ per face
- UVs map (0,0) to bottom-left, (1,1) to top-right (standard texture space)
- Factory methods for common shapes (cube, plane). You'd extend this with sphere, cylinder, etc.

### Step 3: Scene Object

`Models/SceneObject.swift`:
```swift
import MetalKit

class SceneObject {
    var mesh: Mesh
    var texture: MTLTexture?
    var position: SIMD3<Float>
    var rotation: SIMD3<Float>  // Euler angles (pitch, yaw, roll)
    var scale: SIMD3<Float>

    init(mesh: Mesh, texture: MTLTexture? = nil) {
        self.mesh = mesh
        self.texture = texture
        self.position = SIMD3(0, 0, 0)
        self.rotation = SIMD3(0, 0, 0)
        self.scale = SIMD3(1, 1, 1)
    }

    func modelMatrix() -> float4x4 {
        let translation = float4x4(translationX: position.x, y: position.y, z: position.z)

        let rotationX = float4x4(rotationAngle: rotation.x, x: 1, y: 0, z: 0)
        let rotationY = float4x4(rotationAngle: rotation.y, x: 0, y: 1, z: 0)
        let rotationZ = float4x4(rotationAngle: rotation.z, x: 0, y: 0, z: 1)
        let rotationMatrix = rotationZ * rotationY * rotationX

        let scaleMatrix = float4x4(scaleX: scale.x, y: scale.y, z: scale.z)

        return translation * rotationMatrix * scaleMatrix
    }
}
```

Separation of concerns: `SceneObject` owns transform and references to mesh/texture, but doesn't know about rendering. Renderer iterates scene objects and draws them.

### Step 4: Camera

`Camera.swift`:
```swift
import simd

class Camera {
    var position: SIMD3<Float>
    var pitch: Float  // X-axis rotation (radians)
    var yaw: Float    // Y-axis rotation (radians)

    var fov: Float
    var aspectRatio: Float
    var nearZ: Float
    var farZ: Float

    init() {
        position = SIMD3(0, 1.6, 5)  // Eye height, back a bit
        pitch = 0
        yaw = 0

        fov = radians(fromDegrees: 60)
        aspectRatio = 1.0
        nearZ = 0.1
        farZ = 100
    }

    func viewMatrix() -> float4x4 {
        // Camera rotation
        let rotationX = float4x4(rotationAngle: pitch, x: 1, y: 0, z: 0)
        let rotationY = float4x4(rotationAngle: yaw, x: 0, y: 1, z: 0)
        let rotation = rotationY * rotationX

        // Camera translation (negative because we're moving the world)
        let translation = float4x4(translationX: -position.x, y: -position.y, z: -position.z)

        return rotation * translation
    }

    func projectionMatrix() -> float4x4 {
        return float4x4(perspectiveProjectionFov: fov,
                       aspectRatio: aspectRatio,
                       nearZ: nearZ,
                       farZ: farZ)
    }

    func rotate(pitch deltaPitch: Float, yaw deltaYaw: Float) {
        pitch += deltaPitch
        yaw += deltaYaw

        // Clamp pitch to prevent over-rotation
        pitch = max(-.pi/2, min(.pi/2, pitch))
    }

    func move(forward: Float) {
        // Move along look direction
        let direction = SIMD3<Float>(
            sin(yaw),
            0,  // Don't move vertically when "walking forward"
            -cos(yaw)
        )
        position += direction * forward
    }
}
```

**Key Points**:
- **View Matrix**: Inverse of camera transform (we move the world, not the camera)
- **Pitch Clamping**: Prevents flipping upside down (±90° limit)
- **move()**: Moves along XZ plane (horizontal) even if looking up/down

Python equivalent:
```python
class Camera:
    def __init__(self):
        self.position = np.array([0, 1.6, 5])
        self.pitch = 0
        self.yaw = 0

    def view_matrix(self):
        rot_x = rotation_matrix(self.pitch, [1, 0, 0])
        rot_y = rotation_matrix(self.yaw, [0, 1, 0])
        rot = rot_y @ rot_x
        trans = translation_matrix(-self.position)
        return rot @ trans
```

### Step 5: Renderer

`Renderer.swift`:
```swift
import MetalKit

class Renderer: NSObject, MTKViewDelegate {
    var device: MTLDevice!
    var commandQueue: MTLCommandQueue!
    var pipelineState: MTLRenderPipelineState!
    var depthStencilState: MTLDepthStencilState!

    var camera: Camera
    var sceneObjects: [SceneObject] = []

    weak var metalView: MTKView?

    init(metalView: MTKView) {
        self.camera = Camera()
        super.init()
        self.metalView = metalView
        setupMetal()
        createPipeline()
        createDepthStencilState()
        setupScene()
    }

    func setupMetal() {
        device = MTLCreateSystemDefaultDevice()
        commandQueue = device.makeCommandQueue()
    }

    func createPipeline() {
        let library = device.makeDefaultLibrary()
        let vertexFunction = library?.makeFunction(name: "scene_vertex")
        let fragmentFunction = library?.makeFunction(name: "scene_fragment")

        let descriptor = MTLRenderPipelineDescriptor()
        descriptor.vertexFunction = vertexFunction
        descriptor.fragmentFunction = fragmentFunction
        descriptor.colorAttachments[0].pixelFormat = .bgra8Unorm
        descriptor.depthAttachmentPixelFormat = .depth32Float

        pipelineState = try! device.makeRenderPipelineState(descriptor: descriptor)
    }

    func createDepthStencilState() {
        let descriptor = MTLDepthStencilDescriptor()
        descriptor.depthCompareFunction = .less
        descriptor.isDepthWriteEnabled = true
        depthStencilState = device.makeDepthStencilState(descriptor: descriptor)
    }

    func setupScene() {
        // Floor
        let floor = SceneObject(
            mesh: Mesh.createPlane(width: 20, height: 20, device: device),
            texture: TextureLoader.createSolidColorTexture(
                color: SIMD4(100, 100, 120, 255),
                device: device
            )
        )
        floor.position = SIMD3(0, 0, 0)
        sceneObjects.append(floor)

        // Crates scattered around
        for i in 0..<5 {
            let crate = SceneObject(
                mesh: Mesh.createCube(size: 1.0, device: device),
                texture: TextureLoader.createSolidColorTexture(
                    color: SIMD4(150, 75, 50, 255),
                    device: device
                )
            )
            crate.position = SIMD3(
                Float.random(in: -5...5),
                0.5,
                Float.random(in: -5...5)
            )
            crate.rotation = SIMD3(0, Float.random(in: 0...(.pi*2)), 0)
            sceneObjects.append(crate)
        }

        // Walls (Left, Right, Back)
        let wallPositions: [(SIMD3<Float>, SIMD3<Float>)] = [
            (SIMD3(-10, 2.5, 0), SIMD3(0, 0, 0)),           // Left
            (SIMD3(10, 2.5, 0), SIMD3(0, 0, 0)),            // Right
            (SIMD3(0, 2.5, -10), SIMD3(0, .pi/2, 0))        // Back
        ]

        for (pos, rot) in wallPositions {
            let wall = SceneObject(
                mesh: Mesh.createCube(size: 1.0, device: device),
                texture: TextureLoader.createSolidColorTexture(
                    color: SIMD4(80, 80, 90, 255),
                    device: device
                )
            )
            wall.position = pos
            wall.rotation = rot
            wall.scale = SIMD3(0.5, 5, 20)  // Thin, tall, wide
            sceneObjects.append(wall)
        }
    }

    // MARK: - MTKViewDelegate

    func mtkView(_ view: MTKView, drawableSizeWillChange size: CGSize) {
        camera.aspectRatio = Float(size.width / size.height)
    }

    func draw(in view: MTKView) {
        guard let drawable = view.currentDrawable,
              let descriptor = view.currentRenderPassDescriptor else { return }

        let commandBuffer = commandQueue.makeCommandBuffer()!
        let renderEncoder = commandBuffer.makeRenderCommandEncoder(descriptor: descriptor)!

        renderEncoder.setRenderPipelineState(pipelineState)
        renderEncoder.setDepthStencilState(depthStencilState)

        let viewMatrix = camera.viewMatrix()
        let projectionMatrix = camera.projectionMatrix()

        // Draw each object
        for object in sceneObjects {
            let modelMatrix = object.modelMatrix()
            var uniforms = Uniforms(
                modelMatrix: modelMatrix,
                viewProjectionMatrix: projectionMatrix * viewMatrix,
                normalMatrix: modelMatrix.upperLeft3x3()
            )

            renderEncoder.setVertexBuffer(object.mesh.vertexBuffer, offset: 0, index: 0)
            renderEncoder.setVertexBytes(&uniforms, length: MemoryLayout<Uniforms>.stride, index: 1)

            renderEncoder.setFragmentTexture(object.texture, index: 0)
            renderEncoder.setFragmentBytes(&uniforms, length: MemoryLayout<Uniforms>.stride, index: 0)

            renderEncoder.drawIndexedPrimitives(
                type: .triangle,
                indexCount: object.mesh.indexCount,
                indexType: .uint16,
                indexBuffer: object.mesh.indexBuffer,
                indexBufferOffset: 0
            )
        }

        renderEncoder.endEncoding()
        commandBuffer.present(drawable)
        commandBuffer.commit()
    }
}

struct Uniforms {
    var modelMatrix: float4x4
    var viewProjectionMatrix: float4x4
    var normalMatrix: float3x3
}

extension float4x4 {
    func upperLeft3x3() -> float3x3 {
        return float3x3(
            SIMD3(columns.0.x, columns.0.y, columns.0.z),
            SIMD3(columns.1.x, columns.1.y, columns.1.z),
            SIMD3(columns.2.x, columns.2.y, columns.2.z)
        )
    }
}
```

**Notes**:
- **Normal Matrix**: Upper-left 3×3 of model matrix. Used to transform normals in shader. If you use the full 4×4 matrix for normals, non-uniform scaling breaks lighting.
- **Per-Object Rendering**: Loop through objects, set buffers/textures, draw. For thousands of objects, you'd batch by material.
- **setVertexBytes()**: Small uniform struct, no need for a persistent buffer

### Step 6: Shaders with Lighting

`SceneShaders.metal`:
```metal
#include <metal_stdlib>
using namespace metal;

struct Vertex {
    float3 position [[attribute(0)]];
    float3 normal [[attribute(1)]];
    float2 texCoord [[attribute(2)]];
};

struct Uniforms {
    float4x4 modelMatrix;
    float4x4 viewProjectionMatrix;
    float3x3 normalMatrix;
};

struct VertexOut {
    float4 position [[position]];
    float3 worldNormal;
    float2 texCoord;
};

vertex VertexOut scene_vertex(Vertex in [[stage_in]],
                              constant Uniforms& uniforms [[buffer(1)]]) {
    VertexOut out;

    // Transform position to clip space
    float4 worldPos = uniforms.modelMatrix * float4(in.position, 1.0);
    out.position = uniforms.viewProjectionMatrix * float4(in.position, 1.0);

    // Transform normal to world space
    out.worldNormal = normalize(uniforms.normalMatrix * in.normal);

    out.texCoord = in.texCoord;

    return out;
}

fragment float4 scene_fragment(VertexOut in [[stage_in]],
                               texture2d<float> colorTexture [[texture(0)]],
                               constant Uniforms& uniforms [[buffer(0)]]) {
    constexpr sampler textureSampler(mag_filter::linear, min_filter::linear);

    // Sample texture
    float4 baseColor = colorTexture.sample(textureSampler, in.texCoord);

    // Lighting
    float3 lightDirection = normalize(float3(0.5, -1.0, 0.3));  // Diagonal from above
    float diffuse = max(dot(in.worldNormal, -lightDirection), 0.0);
    float ambient = 0.3;

    float lighting = ambient + diffuse * 0.7;

    return float4(baseColor.rgb * lighting, baseColor.a);
}
```

**Shader Points**:
- **Normal Transformation**: Normals transform differently than positions (use normal matrix, not MVP)
- **Directional Light**: Fixed direction, represents sun/distant light
- **Lambertian Diffuse**: `dot(normal, light)` - surface perpendicular to light gets full brightness
- **Ambient**: Constant term so unlit surfaces aren't black

### Step 7: Scene View with Gestures

`SceneView.swift`:
```swift
import SwiftUI
import MetalKit

struct SceneView: View {
    var body: some View {
        SceneMetalView()
            .ignoresSafeArea()
    }
}

struct SceneMetalView: UIViewRepresentable {
    func makeCoordinator() -> Renderer {
        Renderer(metalView: MTKView())
    }

    func makeUIView(context: Context) -> MTKView {
        let metalView = MTKView()
        metalView.device = MTLCreateSystemDefaultDevice()
        metalView.delegate = context.coordinator
        metalView.clearColor = MTLClearColor(red: 0.5, green: 0.7, blue: 1.0, alpha: 1.0)  // Sky blue
        metalView.colorPixelFormat = .bgra8Unorm
        metalView.depthStencilPixelFormat = .depth32Float
        metalView.preferredFramesPerSecond = 60

        // Add gesture recognizers
        let panGesture = UIPanGestureRecognizer(
            target: context.coordinator,
            action: #selector(Renderer.handlePan(_:))
        )
        metalView.addGestureRecognizer(panGesture)

        let pinchGesture = UIPinchGestureRecognizer(
            target: context.coordinator,
            action: #selector(Renderer.handlePinch(_:))
        )
        metalView.addGestureRecognizer(pinchGesture)

        context.coordinator.metalView = metalView

        return metalView
    }

    func updateUIView(_ uiView: MTKView, context: Context) {}
}

extension Renderer {
    @objc func handlePan(_ gesture: UIPanGestureRecognizer) {
        let translation = gesture.translation(in: gesture.view)
        let sensitivity: Float = 0.005

        camera.rotate(
            pitch: -Float(translation.y) * sensitivity,
            yaw: Float(translation.x) * sensitivity
        )

        gesture.setTranslation(.zero, in: gesture.view)
    }

    @objc func handlePinch(_ gesture: UIPinchGestureRecognizer) {
        if gesture.state == .changed {
            let delta = Float(1.0 - gesture.scale) * 0.5
            camera.move(forward: delta)
            gesture.scale = 1.0
        }
    }
}
```

**Gesture Handling**:
- **Pan**: Drag to rotate camera. Translation delta → pitch/yaw change
- **Pinch**: Scale factor → move forward/backward
- **setTranslation(.zero)**: Resets gesture state so next callback gets delta, not absolute
- **@objc**: Required for Objective-C runtime (UIKit gesture recognizers use target-action pattern)

## Common Pitfalls

### 1. Normal Transformation

Using model matrix for normals breaks with non-uniform scaling:
```swift
wall.scale = SIMD3(0.5, 5, 20)  // Thin wall
```

If you transform normals with this, they get squished too. Normal matrix (upper-left 3×3 of inverse-transpose of model matrix) corrects this. For our case (no non-uniform scaling in rotation), upper-left 3×3 works. For complex transforms, compute proper normal matrix.

### 2. Gesture Coordinate Systems

Pan gesture translation is in view coordinates (pixels). Camera rotation is in radians. The `sensitivity` constant converts between them. Too high = twitchy camera, too low = sluggish.

### 3. Texture Coordinate Wrapping

If UVs go outside [0,1], sampler wrapping mode determines behaviour:
- `.repeat`: Tiles texture (good for floors)
- `.clampToEdge`: Stretches edge pixels
- `.mirrorRepeat`: Mirrors texture

We used default (repeat). For non-tileable textures (like a painting), use clampToEdge.

### 4. Depth Buffer Precision

`.depth32Float` is fine for most scenes. Z-fighting (flickering when surfaces overlap) happens when near/far ratio is huge. Our 0.1/100 ratio is 1:1000, well within precision. For planetary scales, use reversed-Z or logarithmic depth.

### 5. Camera Movement and Disorientation

Moving along view direction (including vertical) feels weird in first-person. Our `move()` locks to XZ plane. For flight simulators, you'd use full 3D movement.

## Performance Notes

Drawing 8 objects (floor + 5 crates + 3 walls) with textures and lighting: ~0.2ms per frame on iPhone 13.

Bottleneck isn't rendering, it's iteration overhead (8 draw calls). For 1000 objects, you'd batch by material:
1. Sort objects by texture
2. One draw call per texture (instanced rendering)

Current approach is clear and sufficient for scenes with <100 objects.

## Extending This

Next-level improvements:

1. **Normal Mapping**: Per-pixel normals from texture, makes flat surfaces look detailed
2. **Shadow Mapping**: Render from light's POV to create shadows
3. **Skybox**: Cube map for environment (instead of flat color background)
4. **Frustum Culling**: Don't render objects outside camera view
5. **LOD**: Swap to simpler meshes for distant objects

But you've now got the foundation: textured 3D scene with lighting and camera control.
