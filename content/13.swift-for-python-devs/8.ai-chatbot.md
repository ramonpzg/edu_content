# Tutorial 8: AI Chatbot

Build a fully-functional chatbot using OpenAI's API with local SQLite persistence. Networking, async/await, database operations, and proper error handling.

## What We're Building

A chat application featuring:
- Conversation with OpenAI's GPT models
- Message history persisted to SQLite
- Multiple conversation threads
- Streaming responses (text appears word-by-word)
- API key management (secure storage)
- Offline mode (view past conversations)
- Token usage tracking
- Error handling for network failures

This isn't a toy example. It's production-ready architecture minus the polish.

## Core Concepts

### Async/Await in Swift

Swift's structured concurrency:
```swift
func fetchData() async throws -> Data {
    let (data, _) = try await URLSession.shared.data(from: url)
    return data
}

// Call it
Task {
    do {
        let result = await fetchData()
    } catch {
        print("Error: \(error)")
    }
}
```

Python equivalent:
```python
async def fetch_data():
    async with aiohttp.ClientSession() as session:
        async with session.get(url) as response:
            return await response.read()

asyncio.run(fetch_data())
```

Swift's version is more integrated (no need for explicit event loop management).

### Codable for JSON

Swift's `Codable` protocol auto-generates JSON encoding/decoding:
```swift
struct User: Codable {
    var name: String
    var age: Int
}

let json = try JSONEncoder().encode(user)
let decoded = try JSONDecoder().decode(User.self, from: json)
```

Python equivalent is `dataclasses` + `json` module (more manual).

### SQLite via Swift

Using `SQLite.swift` library or raw SQL with `FMDB`. We'll use raw SQL for clarity:
```swift
var db: OpaquePointer?
sqlite3_open(dbPath, &db)
sqlite3_exec(db, "CREATE TABLE ...", nil, nil, nil)
```

Looks like C because it is - Swift wrapping C SQLite library.

### Step 1: API Models

`Models/OpenAIModels.swift`:
```swift
import Foundation

// Request
struct ChatCompletionRequest: Codable {
    var model: String
    var messages: [ChatMessage]
    var temperature: Double?
    var maxTokens: Int?
    var stream: Bool?

    enum CodingKeys: String, CodingKey {
        case model, messages, temperature, stream
        case maxTokens = "max_tokens"
    }
}

struct ChatMessage: Codable {
    var role: String  // "system", "user", "assistant"
    var content: String
}

// Response
struct ChatCompletionResponse: Codable {
    var id: String
    var object: String
    var created: Int
    var model: String
    var choices: [Choice]
    var usage: Usage?

    struct Choice: Codable {
        var index: Int
        var message: ChatMessage
        var finishReason: String?

        enum CodingKeys: String, CodingKey {
            case index, message
            case finishReason = "finish_reason"
        }
    }

    struct Usage: Codable {
        var promptTokens: Int
        var completionTokens: Int
        var totalTokens: Int

        enum CodingKeys: String, CodingKey {
            case promptTokens = "prompt_tokens"
            case completionTokens = "completion_tokens"
            case totalTokens = "total_tokens"
        }
    }
}

// Streaming response
struct StreamResponse: Codable {
    var id: String
    var object: String
    var created: Int
    var model: String
    var choices: [StreamChoice]

    struct StreamChoice: Codable {
        var index: Int
        var delta: Delta
        var finishReason: String?

        enum CodingKeys: String, CodingKey {
            case index, delta
            case finishReason = "finish_reason"
        }
    }

    struct Delta: Codable {
        var role: String?
        var content: String?
    }
}
```

**Codable Notes**:
- `CodingKeys` maps Swift camelCase to JSON snake_case
- Optional properties (`temperature?`) are omitted if nil when encoding
- Nested structs for complex JSON structures

### Step 2: OpenAI Service

`Services/OpenAIService.swift`:
```swift
import Foundation

class OpenAIService {
    private let apiKey: String
    private let baseURL = "https://api.openai.com/v1"

    init(apiKey: String) {
        self.apiKey = apiKey
    }

    func sendMessage(messages: [ChatMessage], model: String = "gpt-4o-mini") async throws -> ChatMessage {
        let url = URL(string: "\(baseURL)/chat/completions")!
        var request = URLRequest(url: url)
        request.httpMethod = "POST"
        request.setValue("Bearer \(apiKey)", forHTTPHeaderField: "Authorization")
        request.setValue("application/json", forHTTPHeaderField: "Content-Type")

        let requestBody = ChatCompletionRequest(
            model: model,
            messages: messages,
            temperature: 0.7,
            maxTokens: 1000,
            stream: false
        )

        request.httpBody = try JSONEncoder().encode(requestBody)

        let (data, response) = try await URLSession.shared.data(for: request)

        guard let httpResponse = response as? HTTPURLResponse else {
            throw OpenAIError.invalidResponse
        }

        guard httpResponse.statusCode == 200 else {
            let errorMessage = String(data: data, encoding: .utf8) ?? "Unknown error"
            throw OpenAIError.apiError(statusCode: httpResponse.statusCode, message: errorMessage)
        }

        let completionResponse = try JSONDecoder().decode(ChatCompletionResponse.self, from: data)

        guard let firstChoice = completionResponse.choices.first else {
            throw OpenAIError.noResponse
        }

        return firstChoice.message
    }

    func streamMessage(messages: [ChatMessage], model: String = "gpt-4o-mini") -> AsyncThrowingStream<String, Error> {
        return AsyncThrowingStream { continuation in
            Task {
                do {
                    let url = URL(string: "\(baseURL)/chat/completions")!
                    var request = URLRequest(url: url)
                    request.httpMethod = "POST"
                    request.setValue("Bearer \(apiKey)", forHTTPHeaderField: "Authorization")
                    request.setValue("application/json", forHTTPHeaderField: "Content-Type")

                    let requestBody = ChatCompletionRequest(
                        model: model,
                        messages: messages,
                        stream: true
                    )

                    request.httpBody = try JSONEncoder().encode(requestBody)

                    let (bytes, response) = try await URLSession.shared.bytes(for: request)

                    guard let httpResponse = response as? HTTPURLResponse,
                          httpResponse.statusCode == 200 else {
                        throw OpenAIError.invalidResponse
                    }

                    for try await line in bytes.lines {
                        guard line.hasPrefix("data: ") else { continue }
                        let jsonString = String(line.dropFirst(6))

                        if jsonString == "[DONE]" {
                            continuation.finish()
                            return
                        }

                        guard let jsonData = jsonString.data(using: .utf8) else { continue }

                        let streamResponse = try JSONDecoder().decode(StreamResponse.self, from: jsonData)

                        if let content = streamResponse.choices.first?.delta.content {
                            continuation.yield(content)
                        }
                    }

                    continuation.finish()
                } catch {
                    continuation.finish(throwing: error)
                }
            }
        }
    }
}

enum OpenAIError: LocalizedError {
    case invalidResponse
    case noResponse
    case apiError(statusCode: Int, message: String)

    var errorDescription: String? {
        switch self {
        case .invalidResponse:
            return "Invalid response from OpenAI"
        case .noResponse:
            return "No response from OpenAI"
        case .apiError(let code, let message):
            return "API Error (\(code)): \(message)"
        }
    }
}
```

**Networking Points**:

1. **URLSession**: Swift's built-in HTTP client. No external dependencies needed.

2. **async/await**: `URLSession.shared.data(for:)` suspends until response arrives. Non-blocking.

3. **Streaming**: `URLSession.shared.bytes(for:)` returns async sequence of bytes. Process line-by-line as they arrive.

4. **AsyncThrowingStream**: Wrapper for async sequences that can throw errors. Like Python's async generator.

5. **Error Handling**: Structured errors with `LocalizedError` protocol for user-friendly messages.

Python equivalent of streaming:
```python
async for line in response.content:
    if line.startswith(b'data: '):
        data = json.loads(line[6:])
        yield data['choices'][0]['delta']['content']
```

### Step 3: Database Service

`Services/DatabaseService.swift`:
```swift
import Foundation
import SQLite3

class DatabaseService {
    private var db: OpaquePointer?
    private let dbPath: String

    init() {
        let fileManager = FileManager.default
        let documentsPath = fileManager.urls(for: .documentDirectory, in: .userDomainMask)[0]
        dbPath = documentsPath.appendingPathComponent("chat.sqlite").path

        openDatabase()
        createTables()
    }

    deinit {
        sqlite3_close(db)
    }

    private func openDatabase() {
        if sqlite3_open(dbPath, &db) != SQLITE_OK {
            print("Error opening database")
        }
    }

    private func createTables() {
        let conversationsTable = """
        CREATE TABLE IF NOT EXISTS conversations (
            id TEXT PRIMARY KEY,
            title TEXT NOT NULL,
            created_at INTEGER NOT NULL
        )
        """

        let messagesTable = """
        CREATE TABLE IF NOT EXISTS messages (
            id TEXT PRIMARY KEY,
            conversation_id TEXT NOT NULL,
            role TEXT NOT NULL,
            content TEXT NOT NULL,
            created_at INTEGER NOT NULL,
            FOREIGN KEY (conversation_id) REFERENCES conversations(id)
        )
        """

        executeSQL(conversationsTable)
        executeSQL(messagesTable)
    }

    private func executeSQL(_ sql: String) {
        var error: UnsafeMutablePointer<CChar>?
        if sqlite3_exec(db, sql, nil, nil, &error) != SQLITE_OK {
            let errorMessage = String(cString: error!)
            print("SQL error: \(errorMessage)")
            sqlite3_free(error)
        }
    }

    // MARK: - Conversations

    func createConversation(title: String) -> Conversation {
        let conversation = Conversation(
            id: UUID().uuidString,
            title: title,
            createdAt: Date()
        )

        let sql = "INSERT INTO conversations (id, title, created_at) VALUES (?, ?, ?)"
        var statement: OpaquePointer?

        if sqlite3_prepare_v2(db, sql, -1, &statement, nil) == SQLITE_OK {
            sqlite3_bind_text(statement, 1, conversation.id, -1, nil)
            sqlite3_bind_text(statement, 2, conversation.title, -1, nil)
            sqlite3_bind_int64(statement, 3, Int64(conversation.createdAt.timeIntervalSince1970))

            if sqlite3_step(statement) != SQLITE_DONE {
                print("Error inserting conversation")
            }
        }

        sqlite3_finalize(statement)
        return conversation
    }

    func fetchConversations() -> [Conversation] {
        var conversations: [Conversation] = []
        let sql = "SELECT id, title, created_at FROM conversations ORDER BY created_at DESC"
        var statement: OpaquePointer?

        if sqlite3_prepare_v2(db, sql, -1, &statement, nil) == SQLITE_OK {
            while sqlite3_step(statement) == SQLITE_ROW {
                let id = String(cString: sqlite3_column_text(statement, 0))
                let title = String(cString: sqlite3_column_text(statement, 1))
                let timestamp = sqlite3_column_int64(statement, 2)
                let createdAt = Date(timeIntervalSince1970: TimeInterval(timestamp))

                conversations.append(Conversation(id: id, title: title, createdAt: createdAt))
            }
        }

        sqlite3_finalize(statement)
        return conversations
    }

    // MARK: - Messages

    func saveMessage(_ message: Message, conversationId: String) {
        let sql = "INSERT INTO messages (id, conversation_id, role, content, created_at) VALUES (?, ?, ?, ?, ?)"
        var statement: OpaquePointer?

        if sqlite3_prepare_v2(db, sql, -1, &statement, nil) == SQLITE_OK {
            sqlite3_bind_text(statement, 1, message.id, -1, nil)
            sqlite3_bind_text(statement, 2, conversationId, -1, nil)
            sqlite3_bind_text(statement, 3, message.role, -1, nil)
            sqlite3_bind_text(statement, 4, message.content, -1, nil)
            sqlite3_bind_int64(statement, 5, Int64(message.createdAt.timeIntervalSince1970))

            if sqlite3_step(statement) != SQLITE_DONE {
                print("Error inserting message")
            }
        }

        sqlite3_finalize(statement)
    }

    func fetchMessages(conversationId: String) -> [Message] {
        var messages: [Message] = []
        let sql = "SELECT id, role, content, created_at FROM messages WHERE conversation_id = ? ORDER BY created_at ASC"
        var statement: OpaquePointer?

        if sqlite3_prepare_v2(db, sql, -1, &statement, nil) == SQLITE_OK {
            sqlite3_bind_text(statement, 1, conversationId, -1, nil)

            while sqlite3_step(statement) == SQLITE_ROW {
                let id = String(cString: sqlite3_column_text(statement, 0))
                let role = String(cString: sqlite3_column_text(statement, 1))
                let content = String(cString: sqlite3_column_text(statement, 2))
                let timestamp = sqlite3_column_int64(statement, 3)
                let createdAt = Date(timeIntervalSince1970: TimeInterval(timestamp))

                messages.append(Message(id: id, role: role, content: content, createdAt: createdAt))
            }
        }

        sqlite3_finalize(statement)
        return messages
    }
}
```

**SQLite Notes**:

1. **Raw C API**: Swift doesn't have a built-in SQLite wrapper. This is the raw C interface.

2. **Prepared Statements**: `sqlite3_prepare_v2()` compiles SQL, `sqlite3_bind_*()` sets parameters (prevents SQL injection).

3. **Memory Management**: `sqlite3_finalize()` releases statement. Forgetting this leaks memory.

4. **Type Conversions**: Manual conversion between Swift types and SQLite types (text, int64, real).

For production, use a library like `SQLite.swift` or `GRDB` for type safety. Raw SQL is educational but error-prone.

Python equivalent:
```python
conn = sqlite3.connect('chat.db')
cursor = conn.execute("SELECT * FROM messages WHERE conversation_id = ?", (conv_id,))
messages = cursor.fetchall()
```

Simpler API, less type safety.

### Step 5: Chat View

`Views/ChatView.swift`:
```swift
import SwiftUI

struct ChatView: View {
    let conversation: Conversation
    @StateObject private var viewModel: ChatViewModel

    init(conversation: Conversation, apiKey: String) {
        self.conversation = conversation
        _viewModel = StateObject(wrappedValue: ChatViewModel(conversation: conversation, apiKey: apiKey))
    }

    var body: some View {
        VStack {
            ScrollViewReader { proxy in
                ScrollView {
                    LazyVStack(spacing: 12) {
                        ForEach(viewModel.messages) { message in
                            MessageRow(message: message)
                                .id(message.id)
                        }

                        if viewModel.isLoading {
                            HStack {
                                ProgressView()
                                Text("Thinking...")
                            }
                            .padding()
                        }
                    }
                    .padding()
                }
                .onChange(of: viewModel.messages.count) { _ in
                    if let lastMessage = viewModel.messages.last {
                        withAnimation {
                            proxy.scrollTo(lastMessage.id, anchor: .bottom)
                        }
                    }
                }
            }

            HStack {
                TextField("Message...", text: $viewModel.inputText)
                    .textFieldStyle(RoundedBorderTextFieldStyle())

                Button(action: viewModel.sendMessage) {
                    Image(systemName: "arrow.up.circle.fill")
                        .font(.system(size: 30))
                }
                .disabled(viewModel.inputText.isEmpty || viewModel.isLoading)
            }
            .padding()
        }
        .navigationTitle(conversation.title)
        .navigationBarTitleDisplayMode(.inline)
        .onAppear {
            viewModel.loadMessages()
        }
    }
}

class ChatViewModel: ObservableObject {
    @Published var messages: [Message] = []
    @Published var inputText: String = ""
    @Published var isLoading: Bool = false

    private let conversation: Conversation
    private let openAIService: OpenAIService
    private let databaseService: DatabaseService

    init(conversation: Conversation, apiKey: String) {
        self.conversation = conversation
        self.openAIService = OpenAIService(apiKey: apiKey)
        self.databaseService = DatabaseService()
    }

    func loadMessages() {
        messages = databaseService.fetchMessages(conversationId: conversation.id)
    }

    func sendMessage() {
        guard !inputText.isEmpty else { return }

        let userMessage = Message(role: "user", content: inputText)
        messages.append(userMessage)
        databaseService.saveMessage(userMessage, conversationId: conversation.id)

        let input = inputText
        inputText = ""
        isLoading = true

        Task {
            do {
                let chatMessages = messages.map { $0.toChatMessage() }
                let response = try await openAIService.sendMessage(messages: chatMessages)

                let assistantMessage = Message(role: "assistant", content: response.content)

                await MainActor.run {
                    self.messages.append(assistantMessage)
                    self.databaseService.saveMessage(assistantMessage, conversationId: self.conversation.id)
                    self.isLoading = false
                }
            } catch {
                await MainActor.run {
                    self.isLoading = false
                    // Show error to user
                    print("Error: \(error)")
                }
            }
        }
    }
}
```

**View Architecture**:
- **@StateObject**: Owns the view model, survives view recreations
- **ScrollViewReader**: Allows scrolling to specific message
- **LazyVStack**: Only renders visible messages (efficient for long conversations)
- **onChange**: Auto-scrolls when new message added

## Common Pitfalls

### 1. API Key Security

Never hardcode API keys:
```swift
// BAD
let apiKey = "sk-proj-..."  // Committed to Git, exposed in binary

// BETTER
let apiKey = ProcessInfo.processInfo.environment["OPENAI_API_KEY"]

// BEST
Use iOS Keychain for secure storage
```

For this tutorial, we're using config file (not in Git). Production apps use Keychain.

### 2. Memory Leaks with Async Tasks

Task closures capture `self`. Without `[weak self]`, you get retain cycles... except Swift's structured concurrency handles this differently:

```swift
Task {
    // Safe: Task doesn't extend self's lifetime
    let result = await self.fetchData()
}
```

But be careful with cancellation - tasks aren't automatically cancelled when view disappears.

### 3. Database Threading

SQLite isn't thread-safe by default. Our implementation runs all DB operations on main thread (simple but slow). For production:
- Use serial dispatch queue for DB access
- Or use library with built-in thread safety (GRDB)

### 4. Error Handling UX

Our error handling just prints to console. Users see nothing. Add proper UI:
```swift
@State private var errorMessage: String?

.alert("Error", isPresented: .constant(errorMessage != nil)) {
    Button("OK") { errorMessage = nil }
} message: {
    Text(errorMessage ?? "")
}
```

### 5. Token Limits

GPT-4 has context limits (8k, 32k, 128k tokens). Long conversations exceed this. Solutions:
- Truncate old messages
- Summarize conversation history
- Use sliding window (last N messages)

Our implementation doesn't handle this - eventually it'll fail with "context too long" error.

## Performance & Costs

**Latency**:
- Network request: ~500ms (depends on response length)
- SQLite write: <1ms
- UI update: <16ms (one frame)

**Costs** (GPT-4o-mini):
- Input: $0.15 per 1M tokens
- Output: $0.60 per 1M tokens
- Average message: ~100 tokens
- 100 messages ≈ $0.01

For production, track usage and set limits.
